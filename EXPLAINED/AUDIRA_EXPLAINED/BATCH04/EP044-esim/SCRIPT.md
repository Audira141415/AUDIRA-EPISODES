# SCRIPT — AE-044 Bagaimana eSIM Menggantikan Kartu SIM Fisik?

Status: DISETUJUI pengguna 2026-11-08 (Setuju, lanjut). Durasi target 60 dtk.
Jumlah kata: **123** → estimasi **49–55 dtk** @135–150 WPM (+ outro AUDIRA ±3 dtk).

Sumber klaim: `research/SOURCE_REGISTER.md`.

## HOOK
Kartu SIM sekarang bisa dipasang tanpa pernah membuka baki SIM.

## KONTEKS
Itulah eSIM. Chipnya sudah disolder di dalam ponsel sejak pabrik, tapi awalnya kosong, belum berisi nomor.

## MEKANISME
Saat kamu membeli eSIM, operator menyiapkan profil nomormu di server. QR code yang kamu pindai tidak berisi nomor, hanya alamat server dan kode pesanan. Ponsel lalu menjemput profil itu sendiri. Chip dan server saling memeriksa sertifikat, dan profil dikirim terenkripsi sampai masuk ke chip.

## REVEAL
Satu chip bisa menyimpan beberapa profil operator, tapi hanya satu atau dua yang aktif bersamaan.

## PAYOFF
Di Indonesia, pindah ke eSIM masih imbauan, belum wajib. Sejak Juli dua ribu dua puluh enam, pelanggan baru mendaftar dengan pindai wajah. Dan tidak semua ponsel mendukung eSIM.

## OUTRO
Jadi kartunya hilang, tapi nomormu tetap ada. Ini AUDIRA Explained.
