# SCRIPT — AE-071 Bagaimana Gedung Dirancang Agar Tidak Mudah Terbakar?

Status: DISETUJUI pengguna 2026-11-10 (Setuju, lanjut). Durasi target 60 dtk.
Jumlah kata: **130** → estimasi **52–58 dtk** @135–150 WPM (+ outro AUDIRA ±3 dtk).

Sumber klaim: `research/SOURCE_REGISTER.md`.

## HOOK
Api di satu ruangan bisa ditahan supaya tidak menjalar ke ruang sebelah. Setidaknya untuk waktu tertentu.

## KONTEKS
Caranya, gedung dibagi menjadi kotak-kotak yang disebut kompartemen. Dinding dan lantainya tahan api, dan ketahanannya diukur dalam menit, misalnya enam puluh menit.

## MEKANISME
Setiap lubang di dinding itu harus ditutup. Pipa dan kabel yang menembusnya disumbat bahan penyetop api. Di plafon, tiap kepala sprinkler punya bulb kaca kecil. Bulb pecah karena panas, jadi hanya kepala di atas api yang menyemprot.

## REVEAL
Bagian paling penting justru pintunya. Pintu tahan api wajib menutup sendiri. Pintu yang diganjal terbuka sama saja dengan melubangi dinding pemisah api.

## PAYOFF
Di gedung lebih tinggi dari dua puluh empat meter, tangga darurat diberi tekanan udara, supaya asap terdorong keluar. Semua ini membeli waktu untuk evakuasi.

## OUTRO
Jadi jangan pernah mengganjal pintu darurat. Ini AUDIRA Explained.
