# Creative Brief

**Judul:** Server yang Menyadap: Kasus Penyadapan Presiden Prabowo dalam 90 Detik

**Angle:** Memisahkan fakta penyidik (4 tersangka, server LIMS, perintah hapus file, pasal yang dipakai) dari klaim yang viral (6.000 nomor, daftar 43 nama, keterlibatan lingkar Solo). Menjawab kenapa nama Jokowi ikut disebut tanpa menuduh.

**Penonton:** pengguna media sosial yang melihat banyak klaim simpang siur soal penyadapan.

**Hook (0-3 dtk):** "Telepon Presiden disadap. Tersangkanya, mantan pucuk pimpinan polisi sendiri."

**Style kit:** sketsa grafit + cat air (lanjutan seri). Dunia kertas: ponsel PRESIDEN, empat tersangka 2x2 berpapan nama, rak server LIMS dengan nomor tersamar, kalender 1 Oktober dan berkas dicoret, gedung Istana dan BIN, stempel klaim vs fakta.

**Warna & huruf:** aksen merah tua #9F1239, kutipan JetBrains Mono (nuansa server dan teknis).

**Anti-reupload:** tanda tangan bergerak (seed `server-penyadap`), label "sketsa ilustrasi AUDIRA" di rak server, "Audira" di narasi penutup, metadata MP4.
