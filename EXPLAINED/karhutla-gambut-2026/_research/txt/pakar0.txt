Ada Bara Api di Bawah Tanah Karhutla Palangka Raya, Apa Itu? Ini Penjelasan Pakar
Tim Redaksi
KOMPAS.com - Unggahan video yang memperlihatkan bara api di bawah tanah di lokasi kebakaran hutan dan lahan (karhutla) di Palangka Raya, Kalimantan Tengah, ramai di media sosial.
Video yang diunggah akun Instagram @asrulputrananda pada Selasa (13/10/2026) itu memperlihatkan bara berwarna merah yang masih menyala di bawah permukaan tanah, meskipun api di permukaan telah padam.
"Malam ini, saya kembali menemukan bara api yang menyala di bawah tanah Palangkaraya, Kalimantan Tengah. Saat kaki menginjak tanah, dan di sekitar pohon yang tumbang, terlihat nyata bahwa api masih menyala di bawah permukaan tanah, Selasa 13 Oct 2026 Jam 21.00 WIB," tulis pengunggah.
Kondisi tersebut, menurut Asrul, menjadi salah satu alasan kebakaran di lahan gambut sulit dipadamkan. Api tidak selalu terlihat di permukaan, tetapi bara masih dapat bertahan dan menjalar di bawah tanah.
Sebagai informasi, Asrul merupakan salah satu relawan Rumah Zakat dari Kalimantan Barat (Kalbar) yang turut membantu penanganan karhutla di Palangka Raya pada Selasa (13/10/2026).
Dalam upaya pemadaman, para relawan membawa peralatan khusus berupa nozzle tanam. Alat ini digunakan untuk mengalirkan air ke lapisan tanah gambut yang terbakar sehingga dapat menjangkau bara api di bawah permukaan.
Lantas, apa penyebab munculnya bara api di bawah permukaan tanah dan mengapa fenomena ini membuat karhutla sulit dipadamkan?

Anggota Ikatan Ahli Bencana Indonesia (IABI), Daryono mengatakan bahwa bara api yang terlihat dalam video tersebut mengindikasikan fenomena kebakaran lahan gambut bawah permukaan atau ground fire/peat fire.
"Setelah saya pelajari, video tersebut adalah fenomena kebakaran lahan gambut bawah permukaan atau yang sering disebut sebagai ground fire/peat fire," ujarnya kepada Kompas.com, Rabu (14/10/2026).
Menurut Daryono, terdapat beberapa karakteristik utama kebakaran gambut bawah permukaan seperti yang terlihat dalam video tersebut. Berikut di antaranya:
Kebakaran ini terjadi ketika api membakar lapisan bahan organik gambut yang kering di bawah permukaan tanah. Akibatnya, kobaran api besar tidak selalu terlihat dari luar.
"Kondisi ini sering kali mengecoh dan sulit dideteksi secara visual dari luar," kata Daryono.
Daryono menjelaskan, meskipun permukaan tanah terlihat aman atau hanya mengeluarkan sedikit asap, bara api di bawahnya masih dapat menyala dengan suhu tinggi.
Menurutnya, bara tersebut dapat terus membakar lapisan gambut dari dalam.
Daryono mengungkapkan, kebakaran gambut sulit dipadamkan karena api dapat merambat di dalam lapisan gambut yang tebal.
"Bara bisa bertahan dan terus membakar bahan organik meskipun api di permukaan sudah tidak terlihat. Karena itu, pemadaman harus dilakukan secara intensif hingga mencapai lapisan yang terbakar," ujarnya.
Ia mengatakan, metode yang digunakan dapat berupa penyiraman hingga ke bagian dalam tanah atau penggalian untuk memastikan bara benar-benar padam.

Lebih lanjut, Daryono menyampaikan bahwa kemunculan bara api di bawah permukaan tanah merupakan fenomena yang umum terjadi pada lahan gambut, terutama ketika kondisinya kering.
"Ya, benar. Bara api di bawah permukaan tanah merupakan fenomena yang umum dan menjadi salah satu karakteristik khas kebakaran lahan gambut, terutama ketika gambut mengalami kekeringan," jelasnya.
Secara ilmiah, fenomena tersebut dikenal sebagai smouldering combustion, yakni proses pembakaran lambat tanpa nyala api terbuka.
Proses ini dapat merambat melalui lapisan bahan organik di bawah permukaan tanah.
Kondisi tersebut membuat kebakaran gambut sulit dipadamkan. Sebab, meskipun api di permukaan terlihat sudah padam, bara di bawah tanah masih dapat bertahan dan kembali memicu kebakaran.
Meski demikian, Daryono mengingatkan bahwa pemeriksaan lapangan tetap diperlukan untuk memastikan material yang terbakar benar-benar gambut, sekaligus mengetahui kedalaman rambatan api.
Video tersebut memang menunjukkan indikasi kuat adanya pembakaran membara, tetapi belum cukup untuk memastikan kedua hal tersebut.
"Fenomena ini menunjukkan mengapa karhutla di lahan gambut tidak cukup ditangani dengan memadamkan api yang terlihat. Keberhasilan pemadaman harus dipastikan hingga bara di bawah permukaan benar-benar padam. Kebakaran gambut memiliki bahaya tersembunyi," ujarnya.
Ia menambahkan, bara yang masih tersisa di dalam lapisan gambut dapat kembali memicu kebakaran sewaktu-waktu.
Oleh karena itu, upaya pemadaman tidak boleh hanya berfokus pada api yang terlihat di permukaan, tetapi juga harus memastikan bara di bawah tanah benar-benar padam.
