# ART DIRECTION: Api Bawah Tanah

Satu lanskap gambut hangus yang dilihat dengan empat cara: dari darat saat malam, sebagai penampang, lewat sensor termal, dan dari peta asap.

| Chapter | Atmosfer | Cahaya | Kamera |
| --- | --- | --- | --- |
| Lubang api (s1-s2) | Malam, asap merah tua | Dari bawah, dari bara | Dekat ke mulut lubang, mundur memperlihatkan relawan, lalu menyelam ke lubang |
| Penampang (s3-s4) | Tanah terbuka | Bara sebagai sumber utama | Lurus ke dinding, bergeser ke kanal |
| Termal (s5) | Pagi berkabut | Datar, palet termal | Dari atas, garis sensor menyapu |
| Peta (s6) | Dari ketinggian | Asap kuning | Terbang barat ke timur, lalu naik |
| Hujan (s7) | Biru dingin, lalu merah lagi | Mendung ke nyala api | Dolly pelan |
| Air (s8) | Malam ke fajar kelabu | Bara padam, langit terang | Mundur perlahan |

Fajarnya sengaja kelabu. Masalahnya belum selesai, jadi film ini tidak ditutup dengan matahari cerah.

Transisi: menyelam ke bara (s2 ke s3), asap gelap (s4 ke s5), kabut kuning (s5 ke s6), dan mendung (s6 ke s7).

Panel membuka ke bawah dan tenggelam saat keluar, karena ceritanya menggali. Kata aktif di subtitle memanas seperti bara, lalu mendingin.

Tidak ada karakter host. Relawan tampil sebagai siluet agar tidak terbaca sebagai orang tertentu.
