# Naskah — Korek Api (EP04, NANOFORGE)

Kata terucap: **209**. Estimasi di 135–150 WPM: **84–93 dtk** (timeline estimasi: ucapan 90,7 dtk, film 93,7 dtk).
Sumber: `research/RESEARCH_REPORT.md` (fakta HIGH/MED saja; tanpa resep atau takaran campuran).

### 1. Hook (s1)
Korek api ini tidak akan menyala di dinding, batu, atau sepatu. Setengah resep apinya ada di kotak.

### 2. Context (s2)
Dulu, korek fosfor putih menyala di mana saja, dan racunnya merusak rahang pekerja pabrik. Gustaf Erik Pasch dari Swedia lalu memisahkan bahannya, tahun 1844. Lundström bersaudara membuatnya massal di tahun 1850-an.

### 3. Main Development (s3–s5)
**s3.** Semua berawal dari kayu aspen atau pinus. Kayunya dikupas berputar jadi lembaran tipis, dipotong jadi batang kecil. Satu gelondong kayu aspen bisa jadi sekitar 370.000 korek.

**s4.** Batang direndam larutan amonium fosfat, supaya kayunya tidak membara setelah api padam. Batang ditancapkan ke sabuk baja berlubang, ujungnya dicelup parafin panas. Parafin membantu api merambat ke kayu.

**s5.** Berikutnya, ujungnya dicelup adonan kepala, ribuan batang sekaligus. Isinya kalium klorat, bahan bakar seperti belerang, bubuk kaca, lem, dan pewarna. Sabuk naik turun sekitar satu jam sampai kepala kering. Kotaknya dioles fosfor merah dan bubuk kaca.

### 4. Explanation (s6)
Merah di kepala korek bukan fosfor, cuma pewarna. Saat digesek, panas gesekan mengubah sedikit fosfor merah jadi sangat reaktif. Ia langsung bereaksi dengan kalium klorat di kepala, dan api menyala.

### 5. Visual Payoff (s7)
Mesin modern bisa membuat sampai 10 juta korek dalam satu shift 8 jam.

### 6. Outro (s8)
Jadi, api kecil ini butuh dua bagian yang bertemu. Ikuti AUDIRA untuk cara pembuatan berikutnya.
