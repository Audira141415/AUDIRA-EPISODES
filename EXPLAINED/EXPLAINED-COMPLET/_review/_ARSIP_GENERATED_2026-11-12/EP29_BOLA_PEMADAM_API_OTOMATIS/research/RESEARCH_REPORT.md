# RESEARCH REPORT — EP29: Bola Pemadam Api Otomatis (Fire Extinguisher Ball)

## 1. Fakta Kunci & Piroteknik Pemadam Kimia
- **Kelemahan APAR Tradisional:**
  - Tabung pemadam konvensional membutuhkan operator manusia yang terlatih dan tidak panik untuk mencabut pin, mengarahkan corong, dan menekan tuas.
  - Jika kebakaran meletus di ruang server, gudang, atau dapur pada malam hari saat penghuni tidur, api membesar sebelum APAR sempat digunakan.
- **Inovasi Bola Pemadam (Elide Fire Ball / AFE Ball):**
  - Bola berbobot ringan sekitar **1,3 kg**, berlapis cangkang busa styrofoam atau plastik remah yang tidak menghasilkan serpihan tajam saat meledak.
  - Dapat dilemparkan ke kobaran api atau dipasang permanen di keranjang braket di atas titik rawan (panel pemutus arus MCB, stopkontak, kompor gas).
- **Mekanisme Pemicu Suhu & Ledakan:**
  - Cangkang bola dililit oleh jaring sumbu piroteknik sensitif panas (*thermal detonating fuse*).
  - Tidak terpengaruh oleh benturan fisik atau asap. Hanya aktif ketika sumbu menyentuh **lidah api terbuka bersuhu > 70°C selama 3 hingga 5 detik**.
  - Muatan picu piroteknik mikro berdaya rendah (sekitar 2–3 gram bubuk mesiu piroteknik aman) meledak dengan suara peringatan dentuman keras **120 desibel** yang berfungsi sekaligus sebagai alarm kebakaran darurat.
- **Aksi Pemadaman Kimia Serbuk ABC:**
  - Di dalam bola tersimpan 1,3 kg bubuk kimia kering **Monoammonium Phosphate ($NH_4H_2PO_4$) 90% (Dry Chemical Powder Class ABC)**.
  - Ledakan mikro menyemburkan kabut serbuk kimia secara radial 360 derajat mencakup radius 1,5 hingga 2 meter (luas area pemadaman $approx 4$ meter persegi).
  - Serbuk menguraikan diri menjadi asam metafosfat yang melapisi bahan bakar padat, mengikat radikal bebas api, dan memutus kontak oksigen seketika dalam hitungan kurang dari 5 detik.

## 2. Rencana Visual 3D (COMICFORGE / INNERWORKS)
- **Beat 1 (0–3 dtk):** Bola merah di atas panel listrik terbakar tersentuh api, meledak kabut putih dalam 3 detik: "MELEDAK UNTUK MEMADAMKAN".
- **Beat 2 (4–17 dtk):** Ruang server kosong tengah malam; korsleting listrik memercikkan kobaran api ke kabel server.
- **Beat 3 (18–40 dtk):** Lidah api 70°C menyulut sumbu piroteknik mikro di permukaan bola; ledakan 120 desibel memecahkan cangkang busa lunak.
- **Beat 4 (41–64 dtk):** Gelombang kejut menyemburkan 1,3 kg serbuk Monoammonium Phosphate ke segala arah 360 derajat dalam bola kabut putih tebal.
- **Beat 5 (65–81 dtk):** Api padam tuntas tanpa oksigen; panel listrik terselamatkan dari bencana kebakaran gedung total.
- **Beat 6 (82–91 dtk):** Outro khas AUDIRA dengan transisi ke bandul bola pendulum raksasa di puncak Taipei 101.
