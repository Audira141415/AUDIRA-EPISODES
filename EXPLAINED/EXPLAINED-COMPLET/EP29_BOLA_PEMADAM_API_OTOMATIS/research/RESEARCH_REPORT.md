# Research Report — EP29 Bola Pemadam Api Otomatis

Riset 2026-11-13. Nomor `#n` merujuk ke tabel fakta di `SOURCE_REGISTER.md`.

## Ringkasan inti

Bola pemadam api adalah cangkang busa keras berisi bubuk kimia kering. Di luarnya ada sumbu yang terhubung ke muatan bubuk hitam kecil. Saat sumbu tersentuh api, muatan itu memecahkan bola dan menyebarkan bubuk ABC dengan bunyi keras (#6, #9). Bubuk ABC adalah monoamonium fosfat, yang meleleh di atas bahan terbakar, menyelimutinya, dan memutus reaksi berantai pembakaran (#10, #11). Bola bisa digantung di atas titik rawan agar aktif sendiri, atau digelindingkan/dilempar (#2, #3).

Idenya tidak baru. Sejak sekitar 1880 orang memakai "granat api" kaca berisi air garam yang dilempar ke api (#4), dan sudah ada alat berbasis ledakan mesiu sejak paten Ambrose Godfrey 1723 (#21).

Yang jarang disebut iklan: batasnya ditulis oleh pabriknya sendiri. ELIDE FIRE menyebut bola sebagai alat tambahan yang **tidak** menggantikan alat pemadam biasa atau sprinkler (#1). Satu bola 1,4 kg diklaim melindungi hingga 2,5 m³ (#12), jauh lebih kecil dari volume kamar tidur 3 × 3 m (>20 m³, #13). Bola dirancang untuk api tahap awal, sekitar 4 menit pertama (#14), dan tidak boleh dilempar ke api cairan mudah terbakar (#15).

## Sejarah singkat

- 1723: Ambrose Godfrey, tong cairan pemadam dengan bilik mesiu (#21).
- ±1880: granat api kaca berisi air garam (#4); kemudian versi karbon tetraklorida, ditarik 1950an karena beracun (#5).
- 1997–1998: kebakaran Royal Jomtien Hotel memicu Woradech Kaimart menciptakan ELIDE FIRE Ball (#20, klaim pabrik).

## Miskonsepsi yang dibantah

- "Bola pemadam bisa menggantikan APAR/tabung pemadam" → pabrik sendiri menolak klaim ini (#1). Dipakai sebagai hook.
- "Satu bola melindungi satu ruangan" → klaim pabrik 2,5 m³ per bola 1,4 kg (#12); kamar 3 × 3 m >20 m³ (#13).
- "Lempar saja ke api apa pun" → jangan dilempar ke api cairan mudah terbakar (#15).
- "Bola akan aktif karena panas ruangan" → menurut pabrik hanya aktif bila tersentuh api langsung (#7); Wikipedia menulis "triggered by heat" (selisih).

## Angka untuk visual payoff

- **2,5 m³ vs >20 m³** (#12, #13): kotak transparan 2,5 m³ di dalam kamar tidur 3 × 3 m; kamar butuh sekitar delapan kotak.
- ±4 menit (#14): jam pasir untuk "api tahap awal".
- 1,4 kg (#12).

## Catatan naskah

- **Batasan klaim (wajib):** belum ditemukan uji independen (lembaga konsumen, laboratorium, atau makalah) yang mengukur efektivitas bola pemadam (#22). Semua angka kinerja adalah klaim pabrik. Naskah mengucapkan "menurut pabriknya" untuk angka 1,4 kg / 2,5 m³ dan menyebut bola sebagai bantuan tambahan.
- Angka mengacu ke merek ELIDE FIRE (pabrik asal Thailand). Merek lain di pasaran (termasuk tiruan) bisa berbeda; naskah tidak menyebut merek.
- Volume kamar >20 m³ mengasumsikan plafon ≥2,3 m (#13).
- Pabrik menulis "4 menit pertama" dan juga "1–5 menit pertama" (#14); naskah memakai "kira-kira empat menit pertama".
- Angka 120 dB tidak dipakai (hanya klaim pabrik).
- Keamanan: naskah menjelaskan prinsip kerja tanpa detail muatan peledak (tidak menyebut "bubuk hitam/mesiu" untuk bola modern, hanya "muatan kecil"). Tidak ada instruksi membongkar.
- "Tabung pemadam yang lolos uji standar" merujuk ke panduan USFA (UL/ULC listed) (#17); untuk Indonesia, APAR umumnya merujuk SNI (tidak diriset di episode ini, jadi tidak disebut).
- Ejaan fonetik: ABC → "a-be-se"; monoamonium fosfat dibaca apa adanya.
- Ide visual 3D kasar: bola merah tergantung di atas kompor; potongan melintang cangkang busa, bubuk kuning pucat, sumbu melilit; lidah api menyentuh sumbu, bola pecah dalam gerak lambat, awan bubuk; flashback granat kaca abad ke-19; kotak transparan 2,5 m³ dibandingkan kamar tidur penuh; jam pasir 4 menit; label "BUKAN PENGGANTI APAR".
