## 2. Instagram Reels
**Teks cover:** Batu Api = Logam?
**Caption:**
Korek gas kecil, tapi isinya penuh sains:
1. "Batu api" = ferrocerium, campuran besi dan logam tanah jarang cerium (Carl Auer von Welsbach, 1903).
2. Butana di tabung tetap cair karena tertekan lebih dari 2× tekanan udara luar.
3. Tombol ditekan → katup terbuka → butana mendidih jadi gas (titik didih ±0°C).
4. Roda baja menggores ferrocerium, serpihannya menyala sendiri; korek elektrik memakai kristal piezo.
5. Di AS, korek wajib punya pengaman yang menggagalkan minimal 85% anak dalam uji.
