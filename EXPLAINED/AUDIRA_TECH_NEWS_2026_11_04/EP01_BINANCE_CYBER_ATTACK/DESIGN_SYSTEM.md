# Design System: CHAIN OF CUSTODY

| Token | Hex | Pakai |
|---|---|---|
| Deep Black | `#02050A` | Latar, panel |
| Cyber Blue | `#2FA8FF` | Sistem normal, pemulihan |
| Neon Red | `#FF2E3F` | Serangan, aset curian |
| Digital White | `#F3F8FF` | Teks |
| Ice | `#BFE4FF` | Dana dibekukan |
| Caption cyan | `#39D0FF` | Kata aktif |

**Font:** Archivo Black (judul, angka), JetBrains Mono (data, HUD), Inter 900 (catatan, caption)

**Safe zone:** atas 180 px, bawah 380 px.

**Catatan:** Space Grotesk, Bebas Neue, dan Syne tidak termasuk font bawaan HyperFrames, jadi tidak dipakai. Nama font ditulis literal, tidak lewat CSS variable.
