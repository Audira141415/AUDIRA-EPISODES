# Design System: THE TAPE

| Token | Hex | Pakai |
|---|---|---|
| Graphite Black | `#0F1113` | Latar |
| Financial Red | `#E5252A` | Penurunan, kata aktif |
| Metallic Silver | `#C7CCD1` | Label |
| Neutral White | `#F4F5F6` | Teks |
| Hijau data | `#3FA66B` | Hanya saham menguat |

**Font:** Playfair Display 900 (judul koran), Oswald 700 (angka), IBM Plex Mono (label), Montserrat 800 (caption)

**Safe zone:** atas 180 px, bawah 380 px.

**Catatan:** Space Grotesk, Bebas Neue, dan Syne tidak termasuk font bawaan HyperFrames, jadi tidak dipakai. Nama font ditulis literal, tidak lewat CSS variable.
