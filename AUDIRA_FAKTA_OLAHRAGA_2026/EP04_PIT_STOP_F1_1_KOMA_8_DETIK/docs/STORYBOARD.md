# STORYBOARD — Pit Stop F1 1,80 Detik (`EP04`, TOYDIORAMA)

Style: TOYDIORAMA

Waktu di bawah adalah estimasi. Setelah VO dikunci, waktu diganti dengan detik VO (Audio Master Clock). Kamera bergerak terus, tidak ada slide statis. Lapisan di tiap shot: BG / MG / FG / HUD / caption.

**World layout:**
- **Main stage:** panggung walnut dengan kotak pit (cover A) di tengah, garasi GLB di belakang, dan papan "AUDIRA · PIT 04".
- **Chapter stations:** lintasan malam Qatar (kiri belakang panggung), meja ukur ban (kanan depan), dan set pit 1957 (panggung putar, menggantikan pit box saat babak sepia).
- **Between stations:** kamera crane/dolly kontinu di atas panggung, transisi whip-pan searah gerak mobil (vector law: mobil keluar ke kanan, shot berikut masuk dari kiri).
- **Station visibility:** tiap set hanya tampil saat babaknya, jadi satu subjek utama per frame.

**Planes in every shot:**
- **BG:** void `#0E141D`, garasi, dan tiang lampu (babak malam).
- **MG:** mobil F1 mainan dan kru, atau set babak.
- **FG:** ban GLB, cone, dan kabel jack, blur di sepertiga bawah.
- **HUD:** timer, chip tanggal, kartu peran, kartu selisih.
- **Subtitles:** karaoke Space Grotesk 52 px di y ≈ 1300.
