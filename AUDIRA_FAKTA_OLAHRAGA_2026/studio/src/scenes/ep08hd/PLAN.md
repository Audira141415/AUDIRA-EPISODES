## Detail teknis (s6 → s7)
- Studio kit hd2d versi lama: TIDAK ada core/scene/FilmScene, KeyLight, lib/textures. Pakai pola example: `<ThreeCanvas shadows>` + `PoseCamera` (core/camera/PoseCamera.tsx) + `Finish` (core/render/Finish.tsx: frame, background, profile={...COLOR_PROFILES.DOCUMENTARY_WARM, vignette:0.55}, hdri="studio", exposure 1, envIntensity 0.55, ao, focus=jarak kamera→subjek, aperture 0.006, maxBlur 0.03). Fog `<fog attach="fog" args={[bg, 9, 22]}>`.
- GLB: `Model` dari ../ep07/Model.tsx (props id, position, rotation, height). Tersedia di public/glb: bed-6e10e8, bedside-table-3f2b80, table-lamp-e25998, trophy-cabinet-e963ac, bookshelf-5e881a, palm-tree-a307da, front-yard-fir-tree-0a278d, vintage-microphone-stand-c5ba82, brass-post-lamp-984201, street-oil-lamp-d246ea, match-scoreboard-58f51e, advertising-hoarding-run-efe4bc, grandstand-seating-run-fc9023, stand-roof-run-cfd457, spectator-d086fe, clock-tower-752081.
- Polish: RoundedBoxGeo + POLISH.* dari core/polish/Polish.tsx.
- Sprite → tekstur: `rasterize(sprite, pal)` (kits/pixelstory/pixel/sprite.ts) → canvas (salin ke `new Uint8ClampedArray`) → CanvasTexture Nearest, SRGB, cache per key. Anchor di figures.ts sudah +1 (finish pad 1). Plane: tinggi=height, px=height/sprite.h, offset cx=((w-1)/2-anchor.x)*px (negasi bila flip), cy=(anchor.y-(h-1)/2)*px. Material standard map+emissiveMap(intensitas 0.35), alphaTest 0.5, DoubleSide, castShadow. Flip = scale x -1. Yaw = atan2(camX-x, camZ-z) agar menghadap kamera.
- Skala: pemain side ~1.35 unit; lapangan 4.0 (x) × 8.8 (z), net z=0 tinggi 1.04; rotasi grup π/2 → panjang lapangan di sumbu x (C, D, E1; INA kiri hadap kanan, lawan kanan flip).
- Waktu: t = frame/fps; sprite step `Math.floor(t*8)/8`; kamera halus. Kamera y ≥ 3.8, jarak ≥ 9, fov 34. Subjek di y layar 700–1300 (HUD 236–700, caption bottom 400).
- Overlay: import { HookHud, RoomHud, SideHud, CeremonyHud, NetHud, MatchHud, PodiumHud, NightHud } dari ../ep08/Film.tsx; Captions, Wipe dari ../ep08/hud.tsx; useFonts dari kits/pixelstory/typography/fonts.ts; Exposure flash (kits/pixelstory/lighting/overlays.tsx) di SMASH/MATCH_POINT. Overlay dalam div 1080×1920 di-scale width/1080 (pola ep08 Film, SCREEN).
- Root.tsx: `import * as EP08HD from "./scenes/ep08hd/index.ts"`; Ep08HdCover (30f@30 1080×1920), Ep08HdPreview/Final via signed("Ep08", EP08HD.Film) pola baris 91–93.
