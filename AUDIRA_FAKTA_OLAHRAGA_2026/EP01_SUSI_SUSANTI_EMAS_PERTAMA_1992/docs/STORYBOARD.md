# Storyboard — EP01 Susi Susanti, Emas Pertama 1992 (PIXELSTORY)

Catatan:
- 6 set berbeda: arena (cover/depan), kamar atlet, arena sisi samping, net close-up, podium, jalan Jakarta. Arena lebar di OUT = kembali ke set pembuka.
- Semua sprite tanpa wajah; tidak ada logo IOC/BWF/PBSI/maskot; bendera hanya Merah Putih.
- Caption karaoke di pita y 1290–1540; chip/stempel/kartu di atas pita itu dan di bawah y 236; 380 px bawah bersih.
- Tiap adegan punya FG (kepala penonton, tas raket, tiang net, net, fotografer, kelopak bunga) agar ada 3 lapis kedalaman.
