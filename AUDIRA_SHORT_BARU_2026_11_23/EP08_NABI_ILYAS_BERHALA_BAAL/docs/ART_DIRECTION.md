## Look
Kisah dilukis sebagai **iluminasi naskah** di atas lembar vellum yang terbaring di **meja kayu walnut**, diterangi **lilin** (key light hangat dari luar halaman). Tiap babak = satu folio baru:
- **BG (meja)**: kayu walnut berserat gelap, tumpukan kitab dan perkakas penulis di tepi atas (blur, bokeh hangat).
- **MG (folio)**: lembar vellum berserat (≈ 92% lebar frame = hero), tepi deckle, bingkai ganda tinta emas + ornamen sudut, margin bawah berisi baris tulisan tinta pudar.
- **Miniatur (isi folio)**: adegan topik digambar tinta sepia bertepi gelap (outline tinta), warna pigmen hangat (oker, terakota, oxblood, hijau zaitun redup) dan **langit daun emas** pada adegan siang/fajar.
- **FG (meja depan)**: perkakas berbeda tiap babak (pena bulu + tempat tinta, segel lilin AUDIRA, pita penanda, kaca pembesar, penebar pasir, pisau pena), sedikit blur, sehingga bagian bawah frame tidak pernah kosong seragam.
- **HUD**: label vellum bertepi emas, kicker tinta merah rubrik; kartu gelap = kulit oxblood bertulisan emas bertepi tinta.
Kamera: dolly kontinu per folio + parallax miniatur (BG 0.15 / MG 0.5 / FG 1.0); folio sedikit miring dan bergeser.

## Palet (hanya hangat/netral — DILARANG biru, ungu, cyan di cahaya maupun material)

- Emas `#D9A441` / highlight `#FFD07A`, cahaya lilin `#FFD07A` + `#E8A040`, netral `#6A5A48`.
- Rubrik merah `#8A2A14`, oxblood `#5A1E12`, terakota `#B5552E`, zaitun `#6E6A3A`.
- Malam = tinta umber pekat `#2A1A10` → `#4A2E1A` berbintang emas (bukan ungu).
- Berhala Ba'l: perunggu kusam `#7A5A32` → `#3E2A16` (gelap, tanpa wajah).

## Adab visual (keras, tetap)
- Nabi Ilyas tidak tampil sama sekali: tanpa tubuh, siluet, wajah, tangan, bayangan. Kehadiran: cahaya, jejak kaki di pasir, tongkat bersandar di batu, teks seruan.
- Tidak ada penggambaran Allah/malaikat; tidak ada sosok di dalam sinar.
- Kaum: siluet tinta kecil (≤ 12% frame), tanpa fitur wajah, khidmat.
- Kereta api (riwayat israiliyat) hanya ikon kosong roda + nyala, dicap "RIWAYAT ISRAILIYAT".
- Kuil generik kuno (bukan kuil Romawi Baalbek).
- Chip pojok: "SOSOK NABI TIDAK DIGAMBARKAN".
