# ART DIRECTION — EP22 Demam Tamagotchi 1996

Style: PIXELSTORY · Engine Remotion 2D · 1080×1920 @60 (preview 540×960 @30)

## Look
- Set diorama piksel (1 art px = 8 px layar), 3 lapis (back / mid / near) di `CinematicCamera`, disinari ulang tiap frame (lampu titik + kerucut), dither, grain, vignette.
- Palet dasar kit "Lamplight Diorama" (wine-black, amber, ivory) + **palet LCD** untuk semua layar mainan: `#9BBC0F` `#8BAC0F` `#306230` `#0F380F`.
- Aksen 90-an: magenta `#E0407A`, kuning `#F4D03F`, teal kit `#3FB7A8` (hal yang "hidup").
- Telur digital generik: cangkang oval piksel magenta/kuning, 3 tombol bulat, rantai gantungan kunci. Makhluk: gumpal piksel orisinal bernama tanpa merek.

## Lapisan
BG = dinding/rak/langit · MG = subjek (telur, meja, nisan, podium) · FG = benda dekat buram (rantai, kapur, bunga) · HUD = kartu angka piksel + stempel · Caption karaoke di atas zona 380 px bawah.

## Gerak
Kamera kontinu (dolly + drift), wipe piksel di tiap potongan, pop overshoot untuk HUD, stempel slam untuk payoff, shake kecil di impact.
