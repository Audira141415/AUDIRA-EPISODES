# ART DIRECTION — EP18 Longyearbyen, Svalbard (PAPERWORLD)

Style: PAPERWORLD
Engine: Remotion 2D murni (SVG + DOM berlapis, tanpa R3F). Kit PAPERWORLD = resep material & mood (Hukum Mutlak 5): lingkungan disesuaikan ke Arktik (lembah salju, gunung, fjord, permafrost), bukan desa kertas bawaan kit.

## Idea
Satu lembah Arktik pop-up book: kota kertas warna-warni Longyearbyen di kaki gunung salju; kamera menembus tanah (permafrost), masuk arsip, rumah sakit, bukit beruang, lalu masuk ke gunung tempat Seed Vault menyala.

## Look
- **Stage:** diorama kertas berlapis BG (langit pastel bergradasi + gunung salju), MG (kota/lembah/objek utama), FG (gundukan salju kertas, rumput kering), HUD (kartu data kertas + selotip), subtitle karaoke.
- **Lighting (pelajaran juri EP04/EP08 — WAJIB sejak pass pertama):** key light terarah dari kiri-atas (matahari rendah kutub / lampu). Setiap kartu kertas punya **bayangan jatuh panjang searah** (offset 28–40 px kanan-bawah, blur 6–10, rgba(40,30,60,.30)) yang jatuh ke layer di belakangnya, **rim highlight** tepi atas-kiri (krem terang), dan **pool cahaya** (radial gradient hangat) di subjek tiap adegan. Sisi jauh dari cahaya digelapkan (gradien muka kartu). Tidak ada frame flat.
- **Light by chapter:** hook = malam kutub biru-lavender pastel + jendela kuning hangat + aurora mint; konteks = siang biru es cerah; permafrost = potongan tanah hangat coklat dengan lampu dari atas; 1998 = siang putih + lampu tenda kuning; mitos/aturan = kertas krem kantor + cap coral; RS & pesawat = senja peach; beruang = matahari rendah emas, bayangan panjang di salju; payoff vault = biru tua pastel + cahaya pintu turquoise memancar; outro = aurora mint-pink di atas kota.

## Materials
- **Rumah kota (hero 1):** kartu kertas warna (coral, mustard, teal, merah bata, biru) dengan atap segitiga, lipatan crease vertikal, jendela kuning menyala, salju ivory di atap (tepi potong bergerigi).
- **Potongan tanah/permafrost (hero 2):** strip kertas berlapis: salju ivory → lapisan aktif coklat → permafrost biru-abu dengan kristal es potongan; peti kayu kertas + salib kayu.
- **Pintu Seed Vault (hero 3):** baji beton kertas abu hangat menonjol dari lereng, panel cahaya turquoise berlapis; rak kotak benih kertas warna-warni.
- **Beruang kutub:** siluet kertas krem berlapis kartu dengan crease, tanpa detail realistis.
- **Figur manusia:** siluet kertas tanpa wajah, crease + tepi potong (bukan kerucut halus), 20–35% tinggi frame saat jadi subjek.
- **Close-up detail:** guci abu (aksen biru), cap "BUKAN PIDANA" (coral), rambu segitiga beruang (kuning), termometer −18 °C (turquoise).

## Typography (bundled)
- **Chapter/angka:** Anton, 110–180 px.
- **Callout:** kartu ivory + selotip, Space Grotesk 44–64 px, ink #2A2233.
- **Caption 9:16:** Manrope 800 ±62 px, karaoke per kata, kata aktif mustard, bounce ≤1.04, gap 0.4em, plate di atas zona 380 px bawah.

## Depiction rules
- Tidak ada jasad/jenazah realistis: peti tertutup dan salib saja. Virus hanya sebagai ikon lup + tanda silang "TIDAK ADA VIRUS HIDUP".
- Tidak ada senjata ditembakkan; alat pengusir beruang = suar/flare + rambu. Beruang tidak menyerang.
- Label ≥ 40 px di x 60–1020, tidak di 180 px atas / 380 px bawah. Satu subjek jelas per frame; tiap frame contact sheet = set berbeda; kamera selalu bergerak.
- Brand dalam adegan: papan kertas "AUDIRA" di rumah kota (S1/S10) dan label kotak benih (S9).
