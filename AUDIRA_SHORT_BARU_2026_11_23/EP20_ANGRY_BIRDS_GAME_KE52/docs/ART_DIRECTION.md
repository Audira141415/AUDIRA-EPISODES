# ART DIRECTION — EP20 Angry Birds: game ke-52 Rovio

Style: PIXELSTORY · HyperFrames 2D canvas · 1080×1920 @ 60 · 87,7 dtk (VO terkunci)

- **Render**: dunia pixel art digambar ke buffer 180×270, ditampilkan view 135×240 ×8 nearest-neighbour (piksel tajam), kamera {x,y,z} per adegan (push-in, pan, shake di impact), potongan antar adegan = fade INK 0,18 dtk.
- **Palet** (malam hangat → fajar): INK #1a1020, NIGHT #2b1d3a, PLUM #4a2c4f, NAVY #1d2a4a, TEAL #2f6f73, MINT #6fc3a8, GRASS #5fae4a, PIG #8fd14f, RED #d94141, ORG #e07a3a, AMB #f2b84b, CRM #f6e7c1, WH #fff6e8, SKY #7fb6e6, WOOD #9a5f36, WOOD2 #5a3420.
- **Tekstur**: lantai papan/rumput bertekstur + dither Bayer untuk gradasi langit dan bayangan; light pool hangat di subjek; vignette.
- **Karakter generik**: burung bulat (badan merah/kuning/teal, perut krem, alis hitam tebal miring, paruh oranye) tanpa sayap/kaki; babi = gumpalan hijau bermoncong; manusia = sprite 7×14 (siluet untuk tokoh nyata) + plate nama.
- **HUD**: maks label tahap + 1 kartu callout per frame (Silkscreen); angka besar = counter kinetik. Kartu di atas (top ±250 px), caption karaoke Pixelify Sans di 1300 px; safe zone atas 180 px, bawah 380 px.
- **Brand di dunia**: neon "AUDIRA TECH" di gedung bioskop (s7) dan papan di s8; signature bergerak + outro card.
- **Larangan**: logo/karakter resmi Rovio, Angry Birds, Apple, Sega; klaim "bangkrut" (pakai "di ambang bangkrut"); "51 kali gagal" (pakai "51 game, banyak pesanan klien").
