## Alasan
Topiknya game mobile 2009 tentang ketapel dan burung. Pixel art 16-bit membuat kisah studio game terasa seperti level game itu sendiri (counter skor, "GAME OVER", "LEVEL 52"), terbaca jelas di layar ponsel, dan memudahkan ilustrasi generik tanpa karakter resmi.

## Alternatif ditolak
- PAPERWORLD: diorama kertas hangat, tapi kurang "rasa game" untuk kisah studio game; tidak dipilih pengguna.
- COMICFORGE: panel komik dinamis, tapi berisiko mirip gaya promosi resmi dan lebih padat teks; tidak dipilih pengguna.

## Batasan IP
Tanpa logo Rovio/Angry Birds, tanpa karakter resmi, tanpa logo Apple/Sega. Burung = burung bulat generik beralis marah (merah/kuning/teal), babi = gumpalan hijau generik. Tokoh nyata (Jaakko Iisalo) = siluet piksel + papan nama. Chip "ILUSTRASI, BUKAN CUPLIKAN ASLI" sepanjang film.
