# ART DIRECTION — EP19 Flappy Bird Dihapus Pembuatnya (AUDIRA TECH)
Style: PIXELSTORY
Engine: Remotion 2D (kit PIXELSTORY, set albedo di-relight per frame, tanpa R3F)
Format: 1080×1920 @ 60 fps, 89,47 dtk (VO terkunci)

## Konsep
"Uang besar vs hati yang tenang." Dunia nyata = diorama pixel 16-bit berlampu hangat (meja malam, kamar Hanoi, papan tangga lagu kota, etalase lelang). Dunia game = layar di dalam HP dengan palet teal/cyan sendiri, digambar sebagai grid pixel (bukan albedo), sehingga kontras "dunia nyata hangat / dunia game dingin" langsung terbaca.

## Palet
- Dunia nyata: ramp kit PIXELSTORY (ink #0D0809, wine, amber #E8892E, gold #F4B860, ivory #F3E6CC).
- Layar game: teal #3FB7A8, tealDeep #1F6B66, langit #7FD8E0, menara bata #B4552E / #6E2A18, burung oranye-merah #F27A2E / #D02A30.
- Aksen HUD: merah #D02A30 (bahaya/hapus), hijau #2BD46A (naik/rekor), gold (uang).

## Karakter & objek (ilustrasi buatan sendiri)
- Burung AUDIRA: bulat oranye-merah, sayap besar krem, paruh kuning pendek, mata besar putih. Bukan Faby.
- Rintangan: menara bata dengan lampu neon kecil di ujung, bukan pipa hijau.
- Dong Nguyen: siluet duduk di laptop (sprite generik tanpa wajah) + NameCard.
- Tweet: kartu pesan buatan sendiri (bukan UI Twitter asli), chip "ILUSTRASI, BUKAN CUPLIKAN ASLI" di adegan HP.

## Aturan komposisi (pelajaran PIXELSTORY)
- Beda set / sudut kamera tiap beat; lantai bertekstur + dither.
- Maks judul + 1 chip per frame; Stamp ≤ 860 px tanpa rotasi; chip ≥ 250 px dari atas.
- Subjek di atas baris art 160 (layar 1280); caption band 1290–1540.
- Counter selesai tepat di kata angka VO.
- Brand AUDIRA di adegan: stiker laptop (B) dan billboard kota (C1).
