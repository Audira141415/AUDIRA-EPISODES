Engine: Remotion 2D (kit PIXELSTORY, tanpa R3F)

## Alasan
Flappy Bird adalah game pixel 2D, jadi dunia pixel 16-bit adalah bahasa visual aslinya. PIXELSTORY memberi set diorama pixel yang di-relight per frame (meja malam, kamar Hanoi, etalase lelang) sehingga cerita "uang besar vs rasa bersalah" bisa dibawakan dengan cahaya lampu hangat, sementara layar game di dalam HP memakai palet teal tersendiri. Skor PIXELSTORY di memori stabil (EP01 olahraga juri final 4.0).

## Alternatif ditolak
- ARCADECRT: nuansa CRT lebih gelap; skor juri di memori tidak stabil (3.5).
- PANELVERSE: gaya komik, kurang terasa sebagai game mobile.

## Batas visual
Ilustrasi buatan sendiri: tanpa sprite, logo, pipa hijau, atau tangkapan layar asli Flappy Bird. Burung = desain pixel AUDIRA (bulat oranye-merah, sayap besar). Rintangan = menara bata. Dong Nguyen = siluet + name card. Chip "ILUSTRASI, BUKAN CUPLIKAN ASLI".
