# ART DIRECTION — Cara Kerja QRIS (EP01)

Style: BONGKAR

- **Engine:** Remotion 2D SVG (kode `project/src/qris2d/`), pola gold EP12 `ep12/`.
- **Dunia:** studio abu terang (#eceef0 → #dddbd6), benda nyata dibedah: HP, stand QRIS akrilik, warung, gedung bank (issuer, acquirer), hub GPN + 4 rak server switching, peta Indonesia.
- **Cahaya:** kunci dari kiri atas (radial putih 0,85 di 20%/16%), bayangan dingin kanan bawah; sisi kanan objek isometrik lebih gelap dari sisi kiri; rim putih di tepi atas tiap lapisan; bayangan kontak blur di bawah objek.
- **Material:** logam (gradien), kaca akrilik, layar OLED, pelat lapisan berwarna datar dengan tepi terang.
- **Label:** chip hitam + titik merah + garis leader (signature BONGKAR), semua di x 48–1032.
- **Header:** kicker merah + judul hitam (y 232/318). Callout data: big card (y 1290), chip, stempel merah.
- **Karaoke:** pita gelap y 1418 (bawah 380 px bersih).
- **Kamera:** wrapper per scene: push-in 0,975→1,035, drift Y ±35, roll ±0,8°, sway X sin 34 px (G13), crossfade 0,35 dtk. Tidak ada hentakan cepat.
- **Brand di adegan:** "AUDIRA EXPLAINED" di header hook dan papan outro; layar HP pedagang di outro. Tanpa logo organisasi nyata (Bank Indonesia, ASPI, Artajasa, Rintis, Jalin, Alto hanya teks name plate, rule 15).
- **Palet:** ink #1e1f22, chip #1b1b1c, merah #c0141c, oranye paket #ef9420, hijau berhasil #2e9e5b, biru issuer #2f5d9e, ungu acquirer #6a4aa0.
