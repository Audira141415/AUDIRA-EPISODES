## Mitos yang perlu dihindari

- **"Inti Bumi yang cair meletus keluar."** Salah. Magma gunung api di Indonesia berasal dari pelelehan sebagian mantel atas (puluhan–ratusan km), bukan dari inti Bumi. Mantel sebagian besar padat; yang meleleh hanya sebagian (F8).
- **"Magma meleleh karena makin panas di bawah."** Kurang tepat untuk zona subduksi. Pemicu utamanya air dari lempeng yang menunjam, yang menurunkan titik leleh (F8).
- **"Semua letusan meledak-ledak."** Tidak. Hawaii umumnya efusif (lava mengalir), sedangkan Merapi kental dan eksplosif (F10–F12).
- **"Status Awas = pasti meletus besok."** Status adalah tingkat aktivitas hasil pengamatan, bukan ramalan tanggal. Ikuti rekomendasi PVMBG/pemda (F3).
- **"Lempeng bergerak cepat dan terasa."** Hanya ±6–7 cm per tahun (F7); efeknya menumpuk selama jutaan tahun.
- **"Indonesia pasti punya gunung api terbanyak di dunia."** Klaim MAGMA (F1), tapi peringkat dunia tergantung definisi "aktif" (sumber lain menghitung gunung api Holosen, dan AS bisa unggul). Aman ditulis "salah satu yang terbanyak di dunia".
- **Angka "127" dan "Cincin Api 75%" tidak perlu dikutip ke USGS** — kutip PVMBG/MAGMA dan National Geographic yang sudah terverifikasi.
- Jangan sebut angka desibel Krakatau secara pasti (versi 172 dB dan 180 dB beredar); cukup "terdengar hampir 5.000 km jauhnya".

## Hook kandidat

1. "Tahun 1883, ada suara ledakan dari Indonesia yang kedengaran sampai hampir 5.000 kilometer jauhnya. Kok bisa gunung sekuat itu?"
2. "Indonesia punya 127 gunung api aktif. Tapi sebenarnya, kenapa sih gunung bisa meletus?"
3. "Satu gunung di Sumbawa pernah bikin dunia kehilangan musim panasnya. Ternyata pemicunya ada di bawah kaki kita."

## Alur cerita usulan

1. **Hook (0–3 dtk)** — Krakatau 1883 terdengar ±4.800 km (atau 127 gunung api aktif Indonesia). Visual: gelombang suara melingkar dari Selat Sunda melintasi peta Samudra Hindia sampai titik Rodrigues + callout "4.800 km".
2. **Konteks (4–15 dtk)** — Indonesia ada di Cincin Api Pasifik, jalur ±40.000 km tempat ±75% gunung api dunia; Indonesia punya 127 gunung api aktif. Visual: globe berputar, cincin api menyala, zoom ke kepulauan Indonesia dengan titik-titik gunung + counter "127".
3. **Pengembangan (16–45 dtk)** — Lempeng Indo-Australia menunjam ke bawah Eurasia ±6–7 cm/tahun, membawa air; air menurunkan titik leleh mantel sehingga terbentuk magma yang lebih ringan, naik, dan berkumpul di dapur magma. Visual: penampang (cutaway) bumi selatan Jawa, lempeng menyelam, tetesan air, magma menggelembung naik ke dapur magma.
4. **Penjelasan (46–70 dtk)** — Gas terlarut (uap air, CO2, SO2) seperti soda dikocok; saat tekanan turun gas memuai dan mendorong magma keluar. Silika tinggi = magma kental = gas terperangkap = eksplosif (Merapi); silika rendah = encer = lava mengalir (Hawaii). Visual: botol soda dikocok lalu dibuka; split-screen Hawaii (lava mengalir) vs Merapi (kubah lava, awan panas) + bar silika.
5. **Payoff (71–85 dtk)** — Tambora 1815 VEI 7 menurunkan suhu dunia ±0,4–0,7 °C, salju turun Juni 1816 di New York; kini PVMBG memantau gempa, deformasi, dan gas, lalu memberi status Normal–Waspada–Siaga–Awas. Visual: kolom abu menyebar global lalu transisi ke pos pengamatan + seismograf + tangga 4 level berwarna (hijau–kuning–oranye–merah).
6. **Outro (86–90 dtk)** — Nada tenang: gunung api juga memberi tanah subur; kenali statusnya dan ikuti arahan resmi. Visual: sunrise di lereng gunung dengan sawah hijau, outro card AUDIRA.
