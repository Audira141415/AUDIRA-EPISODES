**~00:00.0 - 00:07.2** (s1 · Hook)

Di tengah gurun Turkmenistan, ada lubang raksasa yang terbakar tanpa henti sejak tahun 1971.

**~00:07.2 - 00:15.2** (s2 · Context)

Namanya kawah gas Darvaza, sekitar 260 kilometer di utara ibu kota Ashgabat. Orang menjulukinya Gerbang Neraka.

**~00:15.2 - 00:30.4** (s3 · Development: pengeboran)

Versi yang paling sering diceritakan begini. Tahun 1971, insinyur Soviet mengebor gurun ini untuk mencari minyak. Ternyata di bawah rig ada rongga gas. Tanah runtuh, rig ikut tertelan, dan lubang besar terbuka.

**~00:30.4 - 00:39.7** (s4 · Development: api dinyalakan)

Gas metana terus menyembur keluar. Supaya tidak meracuni sekitar, para insinyur membakarnya, berharap api padam dalam beberapa hari. Mereka salah besar.

**~00:39.7 - 00:57.4** (s5 · Explanation: ukuran + misteri arsip)

Kawah selebar sekitar tujuh puluh meter dan sedalam tiga puluh meter itu menyala sampai sekarang. Anehnya, arsip resminya tidak pernah dibuka. Geolog setempat bahkan menyebut kawah ini runtuh tahun 1960-an dan baru dibakar tahun 1980-an.

**~00:57.4 - 01:07.5** (s6 · Visual Payoff: ke dasar)

Tahun 2013, penjelajah George Kourounis turun ke dasarnya dengan baju tahan panas, dan menemukan bakteri yang hidup di dasar yang panas itu.

**~01:07.5 - 01:19.7** (s7 · Visual Payoff: dipadamkan)

Tahun 2022, presiden Turkmenistan memerintahkan api ini dipadamkan. Sumur-sumur dibor di sekelilingnya untuk menyedot gas, dan tahun 2025 apinya dilaporkan tinggal sepertiga.

**~01:19.7 - 01:27.0** (s8 · Outro)

Gerbang Neraka mulai meredup. Fakta dunia berikutnya, hanya di Audira.
