Tornado ini tidak terbuat dari angin. Ia terbuat dari api.
Dua puluh enam Juli dua ribu delapan belas, Redding, California. Kebakaran Carr sudah tiga hari melahap hutan. Lalu, di tengah asap, sebuah kolom api mulai berputar.
Pusarannya melebar sampai dua ratus tujuh puluh meter, dan menjulang sekitar lima setengah kilometer. Anginnya menembus dua ratus tiga puluh kilometer per jam, setara tornado E F tiga. Menara listrik tumbang, pohon tercabut, dan empat orang tewas.
Bagaimana api bisa berputar? Api raksasa memanaskan udara, dan udara panas naik dengan sangat cepat. Udara di sekitarnya tersedot masuk dari segala arah. Kalau angin di permukaan sedikit saja berputar, putaran itu ikut tertarik ke atas dan menyempit. Seperti penari es yang menarik tangannya: makin sempit, makin kencang. Lahirlah pusaran api, dengan inti lebih dari seribu derajat.
Yang paling mematikan terjadi di Tokyo, tahun seribu sembilan ratus dua puluh tiga. Setelah gempa besar Kanto, puluhan ribu warga mengungsi ke lapangan terbuka bekas depot militer. Api dari kota yang terbakar, dipacu angin topan, berubah menjadi pusaran. Hampir empat puluh ribu orang tewas dalam hitungan menit.
Kebanyakan pusaran api hanya setinggi gedung dan hilang dalam beberapa menit. Tapi bila kebakaran cukup besar, api bisa menciptakan cuacanya sendiri. Ikuti Audira untuk fakta dunia berikutnya.
