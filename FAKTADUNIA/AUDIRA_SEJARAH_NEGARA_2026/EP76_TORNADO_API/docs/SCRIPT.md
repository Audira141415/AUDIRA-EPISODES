## Teks VO (untuk TTS; tulis "Audira", bukan AUDIRA)

[HOOK 0–3]
Tornado ini tidak terbuat dari angin. Ia terbuat dari api.

[CONTEXT]
Dua puluh enam Juli dua ribu delapan belas, Redding, California. Kebakaran Carr sudah tiga hari melahap hutan. Lalu, di tengah asap, sebuah kolom api mulai berputar. (F1, F2)

[MAIN DEVELOPMENT]
Pusarannya melebar sampai dua ratus tujuh puluh meter, dan menjulang sekitar lima setengah kilometer. Anginnya menembus dua ratus tiga puluh kilometer per jam, setara tornado EF3. Menara listrik tumbang, pohon tercabut, dan empat orang tewas. (F3–F7)

[EXPLANATION]
Bagaimana api bisa berputar? Api raksasa memanaskan udara, dan udara panas naik dengan sangat cepat. Udara di sekitarnya tersedot masuk dari segala arah. Kalau angin di permukaan sedikit saja berputar, putaran itu ikut tertarik ke atas dan menyempit. Seperti penari es yang menarik tangannya: makin sempit, makin kencang. Lahirlah pusaran api, dengan inti lebih dari seribu derajat. (F12, F14)

[VISUAL PAYOFF]
Yang paling mematikan terjadi di Tokyo, tahun seribu sembilan ratus dua puluh tiga. Setelah gempa besar Kanto, puluhan ribu warga mengungsi ke lapangan terbuka bekas depot militer. Api dari kota yang terbakar, dipacu angin topan, berubah menjadi pusaran. Hampir empat puluh ribu orang tewas dalam hitungan menit. (F9–F11)

[OUTRO]
Kebanyakan pusaran api hanya setinggi gedung dan hilang dalam beberapa menit. Tapi bila kebakaran cukup besar, api bisa menciptakan cuacanya sendiri. Ikuti Audira untuk fakta dunia berikutnya. (F13)
