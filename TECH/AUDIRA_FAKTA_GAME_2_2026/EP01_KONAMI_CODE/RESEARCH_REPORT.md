## Riset

### 5. Konami Code lahir karena pembuatnya tidak bisa menamatkan gamenya sendiri

**Hook:** Atas, atas, bawah, bawah, kiri, kanan, kiri, kanan, B, A. Kode cheat paling terkenal di dunia ini sebenarnya lupa dihapus.

**Fakta terverifikasi:**
- Kode ini dibuat **Kazuhisa Hashimoto** dari Konami saat memindahkan game arkade *Gradius* (1985) ke NES.
- Hashimoto merasa gamenya **terlalu sulit untuk dimainkan sampai tamat saat pengujian**, jadi dia membuat kode yang memberi semua power-up.
- Kode itu **seharusnya dihapus** sebelum rilis, tapi terlewat dan baru ketahuan menjelang produksi massal. Tim membiarkannya, karena menghapusnya bisa memunculkan bug baru.
- Urutannya cukup mudah diingat penguji, tapi sulit ditekan tanpa sengaja oleh pemain.
- Pertama muncul di *Gradius* NES (1986). Kode ini populer di Amerika lewat *Contra*, yang memberi **30 nyawa**, sehingga dijuluki "Contra Code".
- Kini kode itu jadi easter egg di banyak game dan situs, misalnya situs uang kertas 10 dolar Kanada milik Bank of Canada dan halaman error 404 Discord.
- Hashimoto meninggal **25 Februari 2020**.

**Sudut viral:** Kode cheat paling legendaris itu sebenarnya alat debug yang lupa dihapus.

**Catatan:** Contoh situs web bisa berubah. Cek ulang sebelum disebut di naskah.
