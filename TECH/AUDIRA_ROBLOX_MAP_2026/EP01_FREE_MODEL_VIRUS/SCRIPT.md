# EP 01: Free model Toolbox bisa memuat virus

Seri AUDIRA, RAHASIA BIKIN MAP ROBLOX. Created by Agus Dwi R. Riset 8 November 2026. Style: GLITCHFORGE.

Suara: Cartesia sonic-3, voice `04b567df-2923-4b0c-896b-4b7df0a07e1a`, bahasa id. 217 kata terucap, ujaran 93.485 dtk, film 96.48 dtk.

**[0:00-0:09]** Model gratis di Toolbox Roblox bisa terlihat berguna. Tapi menurut dokumentasi resmi Roblox, ada yang diam-diam memuat virus saat game berjalan.

**[0:09-0:25]** Toolbox dan Creator Store berisi jutaan aset: model, material, plugin, sampai audio. Tinggal klik, langsung masuk ke map kamu. Praktis, dan sering gratis. Banyak developer pemula membangun map pertamanya dari sini.

**[0:25-0:35]** Masalahnya, model bisa membawa script. Ada script yang wajar, misalnya membuat benda bergerak atau memutar suara. Tapi ada juga yang menunggu game berjalan, lalu memanggil aset lain dari luar.

**[0:35-0:48]** Karena itu Creator Store punya larangan khusus. Aset tidak boleh memuat aset lain dari jauh, misalnya lewat require dengan nomor aset, atau loadstring. Kode yang sengaja diacak supaya tidak terbaca juga dilarang.

**[0:48-0:57]** Alasannya sederhana. Kalau kodenya tidak bisa dibaca, kreator tidak bisa memastikan script itu hanya melakukan tugasnya. Kode yang rapi dan terbuka jauh lebih mudah dipercaya.

**[0:58-1:11]** Jadi sebelum memakai free model, buka halaman asetnya. Di sana tertulis jumlah segitiga, vertex, dan jumlah script. Kalau model pohon membawa banyak script, patut dicurigai.

**[1:11-1:24]** Roblox juga memberi jalan aman. Klik kanan modelnya di Explorer, lalu pilih Disable Scripts. Modelnya tetap bisa dipakai, tapi script-nya tidak jalan. Kamu juga bisa menyaring Toolbox hanya untuk kreator terverifikasi.

**[1:24-1:33]** Jadi free model boleh dipakai, asal dicek dulu. Kamu pernah menemukan script aneh di model gratis? Ikuti AUDIRA untuk rahasia bikin map berikutnya.

Ejaan fonetik untuk Cartesia ada di `script-lines.json`.
