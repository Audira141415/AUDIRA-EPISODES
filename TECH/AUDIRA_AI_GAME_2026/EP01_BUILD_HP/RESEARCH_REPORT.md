# EP 01: AI Membuat Game dari HP

Seri AUDIRA, AI BIKIN GAME. Created by Agus Dwi R. Riset 5 November 2026. Fungsi dalam seri: Menjangkau pemula.

## Temuan terverifikasi

1. Build adalah tab pembuatan mobile-first di aplikasi Roblox, diumumkan 16 Juli 2026, memakai prompt teks.
2. Contoh prompt resmi: game petualangan santai di hutan lebat dengan rintangan lingkungan.
3. Build menerjemahkan prompt menjadi spesifikasi, lalu membuat game (agen end-to-end).
4. Build menangani mekanik, lingkungan, karakter, gaya visual, dan suara.
5. Versi dasar gratis, ada opsi berbayar untuk pengguna berat.
6. Pada alpha awal, 71% dari yang membuat game belum pernah memakai Roblox Studio.
7. Alpha per surat Q3: Selandia Baru, Singapura, Serbia, Thailand. Indonesia tidak disebut.
8. Build untuk usia 9+ yang sudah cek usia; game terbit tersedia untuk usia 16+.

## Batasan dan keputusan editorial

Roblox menyebut hasilnya "basic game" dan "starting point". Ketersediaan berdasarkan surat Q3 dan bisa berubah. Kalimat "baru pertama kali membuka alat pembuat game Roblox" adalah penafsiran dari angka 71%, perlu dicek saat review naskah.
