## 5 judul usulan

### EP06 — "Bikin Lagu Sendiri Pakai Gemini, Lengkap dengan Lirik"
- **Sinyal**: "cara membuat lagu dengan ai" (gratis, di hp).
- **Langkah terverifikasi (S12)**: gemini.google.com → di bawah kotak teks: Upload & tools → Create music → (opsional) unggah gambar/video sebagai konteks → tulis prompt. Pilihan: durasi pendek (±1 menit) atau penuh (±2–3 menit), dengan/tanpa vokal, genre. Lagu penuh perlu model "Pro". Model musiknya Lyria; Gemini membuat musik dan lirik; hasil bisa diunduh dan dibagikan.
- **Syarat wajib disebut**: 18+, masuk akun Google, Keep Activity harus aktif.
- **Contoh prompt dari sumber**: lagu pendek tentang Renaisans Italia; beat lo-fi santai dengan melodi piano.

### EP07 — "Bikin Aplikasi Tanpa Coding Pakai Canvas di Gemini"
- **Sinyal**: "bikin aplikasi pakai ai" (gratis, aplikasi kasir, android).
- **Langkah terverifikasi (S13)**: gemini.google.com → Add Files → Canvas → tulis prompt (mis. aplikasi kalkulator kasir) → lihat Preview → tab Code untuk melihat/mengubah kode → Show console untuk error → pilih bagian untuk diedit → Share & export untuk membagikan tautan aplikasi. Canvas juga bisa membuat dokumen, slide, kuis, infografis, halaman web.
- **Peringatan**: aplikasi hasil AI tetap perlu dites; jangan simpan data pelanggan sensitif di aplikasi coba-coba.

### EP08 — "Ngobrol Pakai Kamera: Gemini Live Lihat Apa yang Kamu Lihat"
- **Sinyal**: "gemini live" (camera, samsung).
- **Langkah terverifikasi (S14)**: buka aplikasi Gemini → ketuk Live (atau geser kiri) → mulai bicara → Turn on video streaming untuk kamera, Turn on screen sharing untuk berbagi layar → Hold/End untuk menghentikan. Suara Gemini bisa diganti (tidak di semua bahasa).
- **Belum terverifikasi**: dukungan bahasa Indonesia penuh untuk mode kamera dan jenis HP yang didukung. Wajib dicek di HP sebelum naskah dikunci.

### EP09 — "Riset 5 Menit Jadi Laporan Lengkap: Deep Research Gemini"
- **Sinyal**: "deep research gemini".
- **Langkah terverifikasi (S15)**: gemini.google.com → pilih Deep Research → tulis topik → (opsional) tambah sumber: Gmail, Drive, file, notebook NotebookLM → Edit plan → Start research → laporan biasanya 5–10 menit, boleh ditinggal (ada notifikasi) → buka laporan → Create Audio Overview untuk versi audio.
- **Syarat**: 18+, masuk akun. Visual grafik di laporan hanya untuk paket Ultra (jangan dijanjikan).
- **Sudut**: cocok untuk pelajar/pekerja; tetap cek sumber yang dikutip.

### EP10 — "Chat AI-mu Disimpan? Cara Hapus Riwayat Gemini"
- **Sinyal**: "hapus riwayat gemini" (7 varian), "privasi gemini ai", "apakah chat ai aman".
- **Langkah terverifikasi (S16)**: Gemini Apps Activity di My Activity → tinjau prompt, hapus aktivitas, atau Turn off / Turn off and delete activity.
- **Fakta penting**: walau Keep Activity mati, percakapan tetap disimpan di akun sampai 72 jam untuk layanan dan masukan. Saat mati, sebagian fitur (mis. pembuatan musik) tidak tersedia.
- **Sudut**: privasi praktis, tidak menakut-nakuti; sebut trade-off fitur.

## Catatan seri
- Lagi-lagi semua alat Google. Pilihan: tetap seri "Gemini Bisa Apa?" atau ganti satu episode dengan alat lain setelah diverifikasi.
- Kandidat cadangan: **"Cara mematikan Gemini di tombol power"** (sinyal sangat kuat, tapi langkahnya beda per merek HP Samsung/Xiaomi/OPPO dan tidak ada di bantuan Google, jadi butuh verifikasi per HP); **CV + surat lamaran pakai AI** (alat bebas, risiko data pribadi); **AI untuk Excel**.
- Kuota akun gratis (musik, Deep Research, Live) belum terverifikasi; jangan menjanjikan "gratis tanpa batas".
