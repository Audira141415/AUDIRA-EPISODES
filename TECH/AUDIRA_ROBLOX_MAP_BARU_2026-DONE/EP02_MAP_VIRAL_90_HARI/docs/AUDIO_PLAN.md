## Mix

Command (from the Stage B brief):

```
ffmpeg ... [bed]volume=-5dB → sidechaincompress(threshold 0.02, ratio 4, attack 20, release 450) keyed by the voice → amix normalize=0
```

- Output: `studio/public/audio/ep02/full.wav`, 48 kHz stereo, -16.7 LUFS integrated.
- The bed sits about 14–15 dB under the voice.
- The final render gets `full.wav` via `--vo`. There is no `<Audio>` in the Film.
- full.wav is 92.76 s (amix ends with the voice track). The last 0.15 s under the outro card is silent.
