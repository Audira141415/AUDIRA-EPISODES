## EP01 — 70.000 game baru dari AI (berita)
- Build = tab baru di aplikasi Roblox, bikin game dari prompt teks, mobile-first. (S1, S3) HIGH
- Alpha Build mulai Juli 2026 di Selandia Baru; per 1 Sep 2026 ±9.000 game terbit, 71% pembuatnya belum pernah memakai Roblox Studio. (S1, S2) HIGH
- Surat investor Q3 2026: >500.000 pengguna sudah memakai Build dan menerbitkan >70.000 game (alpha di Selandia Baru, Singapura, Serbia, Thailand). (S4, S5) MED
- Surat investor Q3: >80% dari 100 game teratas (jam main) memakai alat AI; unggahan aset harian ke cloud Roblox naik 3x bulan-ke-bulan; pemakai server MCP harian naik hampir 5x. (S4, S5) MED
- "Break and Steal an Egg" dan "Huss Valley" dibuat hampir seluruhnya dengan AI dan masuk top 20 (pemain serentak) di Q3. (S4, S5) MED
- Kutipan surat investor: AI memicu "explosion of content". (S4) MED
- Unintended output Build turun dari 18% ke 3% sejak alpha; ±14% sesi prompt berakhir dipublikasi. (S2) HIGH
- Sisi gelap: klon game viral (Find the Needle, Lethal Company, Buckshot Roulette) muncul di Roblox, kadang sebelum game aslinya rilis; AI mempercepat kloning. (S7) MED
