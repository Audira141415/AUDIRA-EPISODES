# RESEARCH REPORT — Roblox Map Baru (5 short, riset 2026-11-11)

Riset per 11 Nov 2026. Semua angka dari sumber primer Roblox (newsroom, Creator Docs) atau kutipan surat investor Q3 2026 yang dimuat media. Tingkat keyakinan: HIGH = sumber Roblox langsung; MED = dikutip media dari dokumen Roblox.

Seri sebelumnya `AUDIRA_ROBLOX_MAP_2026` sudah membahas free model virus, greybox, heightmap, batas mesh, dan lighting. Seri ini tidak mengulangnya: fokus pada **ledakan jumlah map baru** dan **tips agar map baru tidak tenggelam**.

## EP01 — 70.000 game baru dari AI (berita)
- Build = tab baru di aplikasi Roblox, bikin game dari prompt teks, mobile-first. (S1, S3) HIGH
- Alpha Build mulai Juli 2026 di Selandia Baru; per 1 Sep 2026 ±9.000 game terbit, 71% pembuatnya belum pernah memakai Roblox Studio. (S1, S2) HIGH
- Surat investor Q3 2026: >500.000 pengguna sudah memakai Build dan menerbitkan >70.000 game (alpha di Selandia Baru, Singapura, Serbia, Thailand). (S4, S5) MED
- Surat investor Q3: >80% dari 100 game teratas (jam main) memakai alat AI; unggahan aset harian ke cloud Roblox naik 3x bulan-ke-bulan; pemakai server MCP harian naik hampir 5x. (S4, S5) MED
- "Break and Steal an Egg" dan "Huss Valley" dibuat hampir seluruhnya dengan AI dan masuk top 20 (pemain serentak) di Q3. (S4, S5) MED
- Kutipan surat investor: AI memicu "explosion of content". (S4) MED
- Unintended output Build turun dari 18% ke 3% sejak alpha; ±14% sesi prompt berakhir dipublikasi. (S2) HIGH
- Sisi gelap: klon game viral (Find the Needle, Lethal Company, Buckshot Roulette) muncul di Roblox, kadang sebelum game aslinya rilis; AI mempercepat kloning. (S7) MED

## EP03 — Algoritma 60 detik pertama (tips)
- Sinyal paling penting Recommended for You: play through rate, first play bounce rate (<60 dtk dan 61–180 dtk; sinyal negatif), play days per user (D1, D2–7, D8–28), playtime per user (maks 60 menit/pengguna/game/hari). (S9) HIGH
- Sinyal penting lain: intentional co-play days (main bareng teman), qualified play sessions, spend days, Robux per user. (S9) HIGH
- Sistem memakai fase explore dan expand: lonjakan pemain baru setelah update, lalu diperluas bila kohort itu betah. (S9) HIGH
- RDC 2026: discovery makin sadar usia, melihat melampaui minggu pertama hingga 28 hari; pemain muda suka game pendek, pemain lebih tua game dalam. (S3) HIGH
- Onboarding (FTUE): ajarkan core loop, cepat masuk ke bagian seru, tinggalkan rasa penasaran; level awal ambang XP rendah. (S10) HIGH

## EP04 — Thumbnail anti tenggelam (tips)
- Thumbnail kustom WAJIB untuk dapat impresi dari rekomendasi Home; thumbnail default tidak eligible. (S9) HIGH
- Rasio 16:9, ideal 1920×1080, maks 3 MB. (S11) HIGH
- Thumbnail personalization: aktifkan 2–5 thumbnail; uji coba rata-rata +8,5% qualified play through rate, sebagian game +50%. (S11) HIGH
- Video thumbnail: gameplay asli, maks 3 upload/bulan, dilarang voice-over/narasi, footage dunia nyata, klaim iklan. (S11) HIGH
- Metadata yang menjanjikan hadiah ("Robux! Play now!") tidak diprioritaskan; metadata yang tak sesuai isi kurang terlihat; ikuti tren tapi beri sentuhan sendiri; hindari judul/gambar berulang. (S9) HIGH
- Moments tab: video gameplay → klik main (penuh di AS). (S3) HIGH

## EP05 — Bikin map pakai prompt, cara benar (tips)
- Build fokus game 2D/2.5D: clicker, arcade, collect-and-score, side-scroller, puzzle; 3D menyusul. (S1) HIGH
- Tiap pesan = 1 prompt; ada jatah prompt gratis harian, bisa beli kredit dengan Robux. (S1) HIGH
- Mengedit game Build di Studio mengubahnya permanen jadi game Studio biasa. (S1) HIGH
- Assistant Studio: tulis prompt spesifik, pakai seleksi objek, prompt multi-langkah; contoh resmi "NPC patroli... kejar pemain bila dalam 10 stud". (S12) HIGH
- Scene Generator (diumumkan RDC 2026, "later this year"): prompt teks + gambar referensi → layout fungsional, lalu dirapikan di Studio. (S3) HIGH — status rilis belum dicek; sebut "diumumkan".
- Penilaian Roblox untuk game Build: kualitas spesifikasi, kualitas statis, playtest, visual; game harus terasa jadi, bukan prototipe. (S2) HIGH
