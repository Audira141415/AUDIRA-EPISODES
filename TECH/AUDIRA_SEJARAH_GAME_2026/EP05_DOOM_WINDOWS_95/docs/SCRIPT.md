## EP05_DOOM_WINDOWS_95: Doom Pernah Mengalahkan Windows 95

Style **Y2KCHROME**. 192 kata, estimasi 77–85 dtk pada 135–150 WPM (timeline perkiraan: 77 dtk suara + outro).

- **s1 · Hook** (0–8 dtk): Tahun seribu sembilan ratus sembilan puluh lima, ada satu game yang diperkirakan terpasang di lebih banyak komputer daripada Windows sembilan puluh lima.
- **s2 · Konteks** (8–15 dtk): Namanya Doom, dirilis studio kecil id Software tahun seribu sembilan ratus sembilan puluh tiga untuk komputer MS-DOS.
- **s3 · Konteks** (15–24 dtk): Cara jualnya unik. Doom memakai model shareware: episode pertama dibagikan gratis dan boleh disalin siapa saja. Dua episode sisanya harus dibeli.
- **s4 · Pengembangan** (24–35 dtk): Menurut perkiraan perusahaan, cuma sekitar satu persen pengunduh yang membeli versi lengkap. Tapi itu sudah menghasilkan sekitar seratus ribu dolar per hari di awal penjualan.
- **s5 · Pengembangan** (35–45 dtk): Bulan Mei seribu sembilan ratus sembilan puluh empat, versi gratisnya diperkirakan sudah tersebar lebih dari satu juta kali. Setiap salinan gratis bisa disalin lagi ke komputer lain.
- **s6 · Penjelasan** (45–55 dtk): Akhir tahun seribu sembilan ratus sembilan puluh lima, Doom diperkirakan terpasang di lebih banyak komputer di dunia daripada Windows sembilan puluh lima, sistem operasi baru Microsoft saat itu.
- **s7 · Payoff** (55–69 dtk): Salah satu video promosi Windows sembilan puluh lima bahkan menampilkan Bill Gates yang disisipkan secara digital ke dalam game itu. Tapi ingat, semua angka tadi perkiraan, bukan hitungan pasti.
- **s8 · Outro** (69–77 dtk): Game yang dibagikan gratis justru menyebar paling jauh. Kamu pernah main versi demo gratis yang bikin ketagihan? Ikuti AUDIRA untuk sejarah game berikutnya.
