# FACTS — Kisah dalam Al-Qur'an (5 episode)

Diriset 2026-11-06. Terjemahan ayat: Kementerian Agama RI lewat API quran.com (translation id 33), teks Arab Utsmani dari API yang sama. Teks lengkap per episode ada di `_research/quran/EPxx_*.txt`. Setiap klaim di naskah (`_tools/write-scripts.py`) tercantum di bawah. Level: HIGH = teks ayat langsung atau hadis sahih; MED = tafsir/sirah klasik yang dikutip sumber sekunder; NOTE = khilaf atau dugaan, dan naskah menyebutnya begitu.

## Aturan penggambaran (untuk visual)
Para nabi (Nuh, Yunus, Musa, Muhammad) tidak digambarkan dalam bentuk apa pun. Mereka hadir lewat benda dan cahaya: tongkat, lentera, palu, jejak. Manusia lain hanya siluet tanpa wajah. Tidak ada penggambaran Allah atau malaikat.
