## Fakta terverifikasi
1. Musa telah menyelesaikan masa kerjanya (di Madyan) dan berjalan bersama keluarganya (28:29).
2. Ia melihat api di lereng gunung Thur: "Tunggulah, aku melihat api, mungkin aku bawakan kabar atau sesuluh api agar kalian menghangatkan badan" (28:29; 20:10).
3. Ia dipanggil dari pohon di tepi lembah yang diberkahi (28:30).
4. "Lepaskan kedua terompahmu, sesungguhnya engkau berada di lembah suci Thuwa" (20:12).
5. Tongkat dilemparkan menjadi ular yang merayap cepat; Musa diminta tidak takut, akan dikembalikan seperti semula (20:19-21).
6. Tangan dikepitkan ke ketiak keluar putih bercahaya tanpa cacat, tanda kedua (20:22).
7. Termasuk sembilan mukjizat untuk Firaun (27:12).
8. Perintah: "Pergilah kepada Firaun, sesungguhnya ia telah melampaui batas" (20:24). Musa berdoa "lapangkan dadaku" (20:25) dan meminta Harun sebagai pembantu (20:29-32).

## Catatan
Beda dari EP04 (membelah laut), EP28 (para penyihir), EP32 (bayi di Nil). Adab: tanpa wajah Musa; panggilan tidak divisualkan sebagai sosok, hanya cahaya/pohon.
