# EP 06: NABI IBRAHIM: API YANG TIDAK MEMBAKAR

Seri AUDIRA, KISAH DALAM AL-QUR'AN. Created by Agus Dwi R. Riset 7 November 2026.

## Angle

Kisah api Ibrahim biasanya langsung lompat ke mukjizat. Film ini menunjukkan jalannya: Ibrahim mengajak berpikir lewat bintang, bulan, matahari, lalu lewat patung yang tak bisa bicara, dan baru setelah kalah berdebat kaumnya memilih api.

## Penonton

Penonton 15-35 tahun yang suka logika dan ingin tahu bagaimana iman bisa lahir dari berpikir, bukan sekadar ikut-ikutan.

## Hook (0-3 detik)

Api terbesar yang pernah dinyalakan kaumnya justru tidak membakar. Satu perintah turun: wahai api, jadilah dingin.

## Konsep dipilih

**GRAVIR TEMBAGA: kuil bata Mesopotamia dan barisan patung dalam gaya cetak ukir kuno, Ibrahim hadir lewat satu pelita**

Alternatif yang dipertimbangkan:

- Peta Mesopotamia (ditolak: lokasi tidak penting bagi pesan)
- Animasi tanah liat lucu untuk patung (ditolak: nada terlalu ringan untuk adegan api)

## Art direction

Style kit: VINTAGEFORGE. Cetak ukir tembaga, arsiran garis, perkamen sepia, patina emas

**Palet:** Perkamen #E9DCC0, sepia #6B4A2B, tembaga #B87333, emas #C9A24B, api jingga #E2622B, api dingin #BFE3F0

**Font:** IM Fell English / Cormorant (teks), Amiri (ayat Arab)

**Gerak kamera dan transisi:** Kamera menyusuri kuil seperti membuka pelat ukir, transisi tekan pelat dan arsiran tinta.

## Design system

Kanvas 1080x1920, 30 fps. Safe zone: atas 180 px, bawah 380 px. Panel di x 56-970. Takarir karaoke di 1290-1540 px. Penutup: logo Monolit AUDIRA dan Created by Agus Dwi R.
