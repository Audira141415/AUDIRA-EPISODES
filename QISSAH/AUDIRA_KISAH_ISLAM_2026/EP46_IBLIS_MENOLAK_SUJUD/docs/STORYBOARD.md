Style: PAPERWORLD
Waktu = perkiraan; dikunci ke detik VO setelah `npm run vo` (Audio Master Clock), lalu ditulis di docs/SHOTLIST.md.

**World layout:** satu kotak diorama kertas vertikal; kamera bergerak antar "stasiun" (langit → bumi → ruang sujud → timbangan → jalan manusia → fajar).
