# ART DIRECTION — EP46 Iblis Menolak Sujud (PAPERWORLD)

Style: PAPERWORLD
Engine: Remotion 2D murni (SVG + DOM berlapis, tanpa R3F), pola gold EP18 Svalbard. Kit PAPERWORLD = resep material & mood (Hukum Mutlak 5): lingkungan disesuaikan ke kisah (langit awal penciptaan, bumi kertas, barisan cahaya, jalan manusia), bukan desa kertas bawaan kit.

## Idea
Kotak diorama kertas "sebelum waktu": langit bertingkat, bumi kertas yang baru dibentuk, barisan pilar cahaya yang bersujud, dan satu nyala api yang tetap tegak. Kamera bergerak dari langit ke bumi, ke ruang sujud, ke timbangan api-vs-tanah, ke jalan manusia yang dikepung bayangan dari empat arah, lalu naik ke fajar tobat.

## Look
- **Stage:** BG langit kertas bergradasi berlapis (indigo malam → emas fajar sesuai babak) + bintang potong; MG objek utama per babak; FG lipatan kertas/awan/rumput kertas blur (DOF 9); HUD kartu ayat ivory + selotip; caption karaoke y≈1300.
- **Lighting (WAJIB sejak pass pertama, pelajaran juri PAPERWORLD):** key light terarah kiri-atas; tiap kartu punya bayangan jatuh panjang searah (offset 28–40 px kanan-bawah, blur 6–10, rgba(30,20,40,.32)), rim highlight krem di tepi atas-kiri, pool cahaya radial di subjek. Api Iblis = sumber cahaya sendiri (jingga) yang melempar bayangan panjang ke arah berlawanan dari cahaya ilahi (emas putih); konflik dua cahaya ini adalah bahasa visual film.
- **Light by chapter:** hook = indigo gelap + satu nyala api, bayangan memanjang ke kamera; khalifah = cahaya emas turun ke bumi kertas biru-hijau; tanah & nama = cahaya hangat di gundukan tanah liat, kartu nama melayang dengan glow lembut; sujud = cahaya putih-emas dari belakang barisan pilar, api tegak di tepi kanan dengan pool jingga; api vs tanah = split light jingga (kiri) vs emas tanah (kanan); penangguhan & sumpah = senja ungu, bayangan merayap dari 4 arah; tobat = fajar emas-peach, cahaya naik; outro = langit fajar tenang + lampu kertas.

## Materials
- **Api Iblis (hero 1):** 5–7 lapis kertas potong bentuk lidah api (merah bata → jingga → kuning), tepi potong pucat, bergoyang pelan; bayangannya = siluet kertas ungu-hitam memanjang. Tanpa mata, wajah, tanduk.
- **Gundukan tanah liat (hero 2):** kertas kraft cokelat berlapis kontur seperti peta topografi, crease, serat; disinari dari atas. Tidak ada figur/wajah Adam.
- **Pilar cahaya malaikat (hero 3):** pita kertas kalkir semi-transparan putih-emas, ramping, melengkung menunduk saat sujud. Tanpa kepala/wajah/sayap figuratif.
- **Bumi kertas:** lanskap kertas berlapis biru-hijau-kraft dengan sungai dan pohon potong.
- **Kartu nama-nama:** kartu ivory berisi ikon path (pohon, bintang, sungai, burung, gunung); tanpa tulisan Arab buatan.
- **Timbangan:** karton dengan wadah api (kiri) dan tanah (kanan); stempel coral "QIYAS PERTAMA".
- **Jam pasir kertas:** pasir emas, label kecil "AUDIRA".
- **Jalan manusia:** jalan kertas lurus, figur manusia umum (bukan nabi) siluet kertas tanpa wajah dengan crease (bukan kerucut), 4 bayangan api dari depan/belakang/kanan/kiri.
- **Tobat:** pita cahaya kertas ("beberapa kalimat") turun ke gundukan tanah; api mengecil jadi bayangan.

## Typography (bundled)
- **Chapter/angka:** Anton, 110–170 px.
- **Callout ayat:** kartu ivory + selotip, Space Grotesk 44–60 px, ink; rujukan surah ≥ 36 px.
- **Kutipan:** "AKU LEBIH BAIK DARINYA" di panel gelap rgba(20,14,30,.78) + border kiri jingga, Anton 72 px.
- **Caption 9:16:** Manrope 800 ±62 px, karaoke per kata, kata aktif dawn-gold, bounce ≤1.04, gap 0.4em, plate di atas zona 380 px bawah.

## Depiction rules (adab)
- Tanpa wajah/sosok Adam; Adam = tanah liat + cahaya. Malaikat = pilar cahaya, tanpa wajah/sayap figuratif.
- Iblis = api dan bayangan, bukan monster; tanpa wajah/tanduk/darah, tidak seram vulgar.
- Tidak menampilkan surga/pohon larangan secara figuratif (tidak dibahas di VO).
- Kutipan ayat = terjemahan makna + rujukan surah:ayat, bukan tulisan Arab buatan.
- Label ≥ 40 px di x 60–1020, tidak di 180 px atas / 380 px bawah. Satu subjek jelas per frame; tiap frame contact sheet = set berbeda; kamera selalu bergerak.
- Brand dalam adegan: pita kertas "AUDIRA QISSAH" di bingkai diorama (S1, S9) dan label jam pasir (S6).
