## Fakta terverifikasi
1. Kontribusi tidak harus kode: dokumentasi, desain, organisasi isu, menjawab pertanyaan, mentoring juga dihitung (#1).
2. 28% kontribusi kasual berupa dokumentasi, mengutip studi Steinmacher dkk. Angka ini dikutip dari panduan, bukan dari studi aslinya (#2).
3. Cara mulai: pilih proyek yang sudah dipakai; cek LICENSE, aktivitas commit, respons maintainer terhadap isu dan PR (#1).
4. Tambah /contribute di URL repositori untuk isu ramah pemula; label good first issue / help wanted (#3).
5. CONTRIBUTING.md tampil sebagai tautan saat membuka isu/PR (#4).
6. Alur: fork, push ke branch di fork, buka PR ke branch upstream (#5).
7. Per 2026-11-25: 476.626 isu terbuka berlabel good first issue (#6); first-contributions 56.987 bintang (#7).
8. Komunikasi: beri konteks, riset dulu, singkat, tetap publik (#8).

## Perselisihan / Kontroversi
- Judul/hook akurat; tidak perlu koreksi. Catatan: "typo dihitung" didukung #1 (dokumentasi/typo disebut sebagai kontribusi), tetapi tiap proyek bisa menolak PR trivial; sebut "cek CONTRIBUTING".
- Angka 28% adalah kutipan sekunder; sebut "satu studi mencatat".
- Hitungan good first issue sangat berubah dan mencakup repo terbengkalai; wajib "per tanggal".
- Naskah tidak menyebut Hacktoberfest (halaman aturan tidak berhasil diverifikasi).
