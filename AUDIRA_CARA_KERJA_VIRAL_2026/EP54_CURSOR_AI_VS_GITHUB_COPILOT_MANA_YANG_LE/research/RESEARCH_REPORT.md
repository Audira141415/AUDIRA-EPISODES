# Research Report — Cursor AI vs GitHub Copilot: Mana yang Lebih Worth It untuk Developer Indonesia

Tanggal riset: 2026-11-25. Semua harga dalam USD, per halaman resmi yang dibaca hari ini (harga AI tools cepat berubah).

## Sumber utama

- Halaman harga resmi GitHub Copilot dan GitHub Docs (register #1–#3), HIGH.
- GitHub Blog peluncuran GA 2022 (#4), HIGH.
- Cursor Docs dan halaman harga resmi Cursor (#5–#6), HIGH.
- CNBC soal kesepakatan SpaceX–Cursor (#7), HIGH.
- Wikipedia "Cursor (company)" dan "GitHub Copilot" (#8–#10), MEDIUM, untuk kronologi dan kontroversi.

## Fakta terverifikasi

1. Copilot punya empat paket individu: Free $0, Pro $10, Pro+ $39, Max $100 per bulan. (#1)
2. Copilot Free dibatasi 2.000 completions per bulan dan model level dasar. (#1)
3. Di paket berbayar, code completion dan next edit suggestion tidak memakai kredit dan tidak dibatasi; chat, agent mode, code review, coding agent, dan CLI memakai GitHub AI Credits (1 kredit = $0,01). (#2)
4. Total kredit bulanan: Pro $15, Pro+ $70, Max $200. Pro+ membuka model premium termasuk Opus. (#2)
5. Copilot Student gratis untuk pelajar terverifikasi; Copilot Pro gratis untuk sebagian pengguna (menu docs menyebut jalur pengajar dan maintainer OSS). (#3)
6. Copilot GA 21 Juni 2022 dengan harga $10/bln, sama dengan harga Pro sekarang. (#4)
7. Cursor dibangun dari codebase VS Code, sehingga pengaturan VS Code bisa dipindah. (#5)
8. Paket Cursor sekarang dibundel dengan langganan X dan Grok: Free, Plus $8 (hanya model Grok), Premium $30, Super $100, Ultra $200, Teams $30/user. (#6)
9. Premium ke atas membuka cloud agents, code review Bugbot, dan model pihak ketiga dengan harga API list; pemakaian model pihak ketiga (Claude, GPT, dll.) tidak termasuk biaya bulanan. (#6)
10. SpaceX mendapat hak membeli Cursor $60 miliar (21 Apr 2026); akuisisi rampung 14 Agu 2026. (#7, #8)
11. Juli 2025 Cursor mengubah paket Pro $20 dari 500 request ke batas berbasis pemakaian, lalu minta maaf dan refund. (#9)

## Poin kunci

- Copilot: harga masuk paling murah ($10), autocomplete tak terbatas, kredit hanya untuk chat/agen; gratis untuk pelajar terverifikasi.
- Cursor: editor penuh berbasis VS Code dengan fitur agen kuat, tapi kini paket X/Grok; model non-Grok dibayar terpisah sesuai tarif API, jadi biaya riil bisa jauh di atas $30.
- Kesimpulan aman untuk naskah: mulai gratis, ukur pemakaian sebulan, baru pilih.
