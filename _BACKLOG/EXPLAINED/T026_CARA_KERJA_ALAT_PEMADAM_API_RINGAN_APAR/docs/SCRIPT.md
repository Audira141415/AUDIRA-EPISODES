# Naskah — Cara Kerja Alat Pemadam Api Ringan (APAR)

> DRAF pra-produksi (backlog, 2026-11-26). Difinalkan di tahap 4 setelah style dipilih.
> Short: 190–210 kata @135–150 WPM.

## c00_hook — Hook

- Kata: **17** · estimasi **7 dtk**
- Visual: Lorong kantor generik, kamera dolly cepat ke tabung merah tergantung di dinding; tabung "terbelah" jadi empat siluet isi (tetes air, gelembung busa, serbuk, awan gas). Flash api kecil membesar saat label "salah pilih". HUD chip: "4 jenis isi" (#1).

> Tabung merah di dinding kantormu isinya tidak selalu sama. Salah pilih, api malah bisa membesar. Ini Audira.

## c01_intro — Intro

- Kata: **16** · estimasi **7 dtk**
- Visual: Segitiga api menyala (ikon bahan bakar, panas, oksigen di tiap sudut); satu sudut dicabut dan api padam. HUD callout tiga ikon: "BAHAN · PANAS · OKSIGEN" (#2, #7).

> Api butuh tiga hal sekaligus: bahan bakar, panas, dan oksigen. APAR bekerja dengan memutus salah satunya.

## c02 — Empat golongan api

- Kata: **36** · estimasi **15 dtk**
- Visual: Empat panel berganti cepat: tumpukan kertas dan kayu (A), jeriken bensin (B, tanpa merek), stop kontak dan panel listrik (C), serpihan logam berpijar (D). Lalu wajan minyak dapur dengan label kecil "K". HUD: "Permenaker 04/1980: A · B · C · D" dan chip "Standar AS: + kelas K" (#1, #2, #4).

> Aturan Menteri Tenaga Kerja tahun 1980 membagi kebakaran jadi empat golongan. A untuk benda padat seperti kertas dan kayu, B cairan dan gas, C listrik bertegangan, D logam. Standar Amerika menambah kelas K untuk minyak dapur.

## c03 — Isi tabung: air, busa, CO2

- Kata: **27** · estimasi **11 dtk**
- Visual: Cutaway tiga tabung berjajar. Air menyemprot tumpukan kertas, uap naik (ikon termometer turun); busa menyelimuti genangan bensin; semburan CO2 putih dingin mendorong oksigen keluar dari panel listrik. Tanda silang merah besar saat air diarahkan ke minyak dan kabel (#2, #6).

> Isinya juga beda. Air mendinginkan api golongan A, tapi berbahaya untuk minyak dan listrik. Busa menyelimuti cairan yang terbakar. Karbon dioksida mengusir oksigen, cocok untuk api listrik.

## c04 — Serbuk serbaguna di kantor

- Kata: **30** · estimasi **12 dtk**
- Visual: Cutaway APAR serbuk: ruang tabung berisi serbuk kuning, tekanan gas mendorong serbuk naik lewat pipa sifon ke selang. Serbuk menyelimuti api dan memutus "rantai reaksi" (animasi rantai patah). HUD label tabung generik: "A B C" (#2, #4, #6, #10).

> Yang paling sering terpasang di kantor biasanya serbuk kimia kering serbaguna. Serbuknya menyelimuti bahan bakar dan memutus reaksi kimia api, jadi satu tabung bisa melawan kelas A, B, dan C.

## c05 — Evakuasi dulu, lalu PASS

- Kata: **30** · estimasi **12 dtk**
- Visual: Siluet pekerja tanpa wajah menekan alarm, menoleh ke pintu keluar (papan EXIT generik menyala). Lalu empat kartu kinetik PASS: pin ditarik, nozzle diarahkan ke pangkal api, tuas ditekan, sapuan kiri-kanan. HUD: "P · A · S · S" (#3, #4).

> Tapi APAR hanya untuk api kecil. Bunyikan alarm, pastikan jalan keluar aman, baru pakai teknik PASS: tarik pin, arahkan ke pangkal api, tekan tuas, lalu sapukan ke kiri dan kanan.

## c06 — Aturan pasang dan cek

- Kata: **24** · estimasi **10 dtk**
- Visual: Dinding dengan penggaris vertikal; tabung naik sampai garis "1,2 m"; kamera mundur, dua tabung di lorong dengan garis ukur "≤ 15 m"; zoom ke jarum pengukur tekanan dan label tanggal pemeriksaan. HUD: "1,2 m", "15 m", "2× setahun" (#1).

> Pemasangannya juga diatur. Puncak tabung setinggi 1,2 meter, jarak antartabung maksimal 15 meter, dan diperiksa dua kali setahun. Cek jarum tekanan dan tanggal pemeriksaannya.

## c07_payoff — Payoff + outro

- Kata: **21** · estimasi **9 dtk**
- Visual: Api di ruangan membesar melewati batas "api kecil"; siluet berjalan keluar lewat pintu darurat, layar ponsel generik menampilkan "113" dan "112" besar. Kamera mundur ke lorong kantor aman, tabung merah kembali di dinding. Outro card AUDIRA (#3, #8, #9).

> Kalau api membesar atau kamu ragu, jangan dilawan. Keluar, lalu telepon pemadam kebakaran di 113 atau layanan darurat 112. Ikuti Audira.

## Opsi hook lain

1. Air bisa memadamkan api, tapi siram minyak panas atau kabel menyala, apinya malah makin bahaya. Tabung merah itu tahu bedanya.
2. Di tabung merah kantormu ada tiga huruf kecil: A, B, C. Itu daftar api yang bisa dia lawan.
