# Research Report — Cara Kerja Alat Pemadam Api Ringan (APAR)

> Riset backlog 2026-11-26. Channel @AudiraExplained (rule 15: netral, tanpa wajah/logo/merek nyata). Topik keselamatan: pesan evakuasi wajib.

## Sumber utama

- **OSHA eTool** (Departemen Tenaga Kerja AS): cara kerja APAR, kelas api, jenis isi (#2); langkah evakuasi dan teknik PASS (#3). **29 CFR 1910.157** sebagai pembanding interval cek (#5).

- Pendukung MEDIUM: ANTARA (jenis APAR di Indonesia #6, segitiga api #7, nomor darurat #8, rencana nasional 112 #9), Wikipedia id (bahan serbuk ABC #10, nomor 113 #11).

## Fakta terverifikasi

1. Api butuh bahan bakar, panas, dan oksigen (OSHA menambah reaksi kimia berantai); APAR memadamkan dengan mendinginkan, menyingkirkan oksigen, atau memutus reaksi kimia (#2, #7).
2. Permenaker 04/1980 membagi kebakaran jadi 4 golongan: A padat (kecuali logam), B cair/gas mudah terbakar, C listrik bertegangan, D logam (#1).
3. Permenaker 04/1980 mengenal 4 jenis APAR: air, busa, tepung (serbuk) kering, gas (#1). Standar AS (OSHA/USFA) memakai 5 kelas A, B, C, D, K; K = minyak/lemak masak (#2, #4).
4. Air hanya untuk kelas A; berbahaya pada cairan mudah terbakar (api menyebar) dan listrik (sengatan) (#2).
5. Busa menyelimuti permukaan cairan yang terbakar, cocok untuk A dan B (#6, #7).
6. CO2 menyingkirkan oksigen dan sedikit mendinginkan; untuk kelas B dan C; tidak disarankan untuk kelas A karena bisa menyala lagi (#2).
7. Serbuk kimia kering menyelimuti bahan bakar dan memutus reaksi kimia; versi serbaguna untuk A, B, C; jenis yang paling banyak dipakai (#2, #6). Bahan umum: monoamonium fosfat (#10, MEDIUM, tidak disebut di VO).
8. Teknik PASS: tarik pin, arahkan ke pangkal api, tekan tuas, sapukan kiri-kanan. Sebelumnya: bunyikan alarm, panggil pemadam, pastikan jalur evakuasi; evakuasi bila APAR habis, api membesar, atau ragu (#3, #4).
9. Aturan pasang Permenaker 04/1980: puncak tabung 1,2 m dari lantai (CO2 & serbuk boleh lebih rendah, min 15 cm), jarak antar-APAR maks 15 m, tanda pemasangan 125 cm, tabung sebaiknya merah (#1).
10. Pemeriksaan: 2 kali setahun (jangka 6 dan 12 bulan), termasuk isi dan tekanan tabung; percobaan tekan maks 5 tahun sekali, tanggalnya dicap di pelat logam tabung (#1).
11. Nomor darurat: 113 pemadam kebakaran; 112 layanan darurat terpadu (tersedia di banyak daerah per Juli 2025; integrasi nasional dirintis dari percontohan Bali per September 2026) (#8, #9, #11).

## Perselisihan / Kontroversi

- **Koreksi hook TOPIC.md**: "tiga jenis isi untuk tiga jenis api" **tidak akurat**.
  - Aturan Indonesia (Permenaker 04/1980) menyebut **4 golongan api** (A–D) dan **4 jenis isi** (air, busa, serbuk kering, gas). Standar AS menyebut **5 kelas** (A, B, C, D, K).
  - Pasangan isi dan kelas tidak satu lawan satu: busa untuk A+B, CO2 untuk B+C, serbuk serbaguna untuk A+B+C, sementara kelas D dan K butuh APAR khusus.
  - Satu tabung di dinding kantor biasanya hanya berisi **satu** jenis media (umumnya serbuk ABC), bukan tiga isi.
  - Yang benar dari hook: OSHA memang menyebut **tiga jenis APAR paling umum** (air, CO2, serbuk kering), dan label "A B C" pada APAR serbuk menandai tiga kelas api. Hook dikoreksi menjadi "**isinya tidak selalu sama, salah pilih api bisa membesar**", dan "tiga huruf A, B, C" dipindah ke opsi hook alternatif.
- **Golongan C**: Permenaker = listrik bertegangan; ANTARA #6 menulis kelas C "gas atau listrik" (mencampur kelas B Indonesia/AS dengan kelas C Eropa). Naskah mengikuti Permenaker (C = listrik).
- **"6 klasifikasi"** di ANTARA #7 tidak dipakai (rangkuman campuran standar); naskah memakai 4 golongan Permenaker + 1 kelas K dari standar AS.
- **Interval isi ulang**: Pasal 18 Permenaker menyebut "bahan kimia" diisi setahun sekali, tetapi Lampiran 3 menulis tepung kering 5 tahun. Naskah tidak menyebut interval isi ulang; VO hanya "diperiksa dua kali setahun" + "cek jarum tekanan dan tanggal pemeriksaan". Istilah "kedaluwarsa" tidak dipakai di VO karena aturan memakai jadwal periksa/isi ulang/percobaan tekan, bukan tanggal kedaluwarsa tunggal.
- **Standar lebih baru**: Permenaker 04/1980 masih "Berlaku" di TEMANK3 per 2026-11-26, tetapi bisa ada SNI/peraturan bangunan yang lebih baru (mis. aturan proteksi kebakaran gedung PUPR). Cek ulang status sebelum produksi.
- **Nomor 112**: belum terintegrasi nasional per September 2026 (Bali percontohan, target 2 tahun). VO menyebut 113 lebih dulu, 112 sebagai alternatif.
- **Keselamatan**: VO tidak mengajarkan memadamkan api besar, api logam, atau api minyak dapur dengan APAR; teknik PASS disebut sebagai info umum setelah pesan "hanya untuk api kecil" dan "pastikan jalan keluar". Tidak ada instruksi membuat/mengisi APAR sendiri.
