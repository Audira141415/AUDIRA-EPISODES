# Storyboard — EP04 Mansa Musa: Emas di Kairo (HD2D)

Satu dunia diorama yang utuh, kamera terus bergerak. Semua kunci kamera dan event terikat ke waktu kata di `audio/timeline.json` (lihat `project/src/scenes/mansamusa/camera.ts`, fungsi `W(kata, ke-n)`). Waktu di bawah adalah hasil dari VO yang terkunci.

Tata letak dunia: pasar Kairo + timbangan di titik asal (cover), meja peta voxel Afrika Barat sampai Arab di x ≈ −11, kemah Giza + Sungai Nil + istana Kairo di x ≈ +8…+17. Perpindahan antar set = terbang tinggi di atas gurun dengan tirai senja tipis (gaya transisi zona HD-2D).
